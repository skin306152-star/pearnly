ALINE 官方号后台：建号、开 Messaging API

网址 manager.line.biz，用你平时的 LINE 商用账号登录。

A1　新建官方号

  1. 左侧点 1 Create new，会开一个新标签页。
  1. 1 账号名称（ชื่อบัญชี）：填租户公司名或前缀，最多 20 字，客户在 LINE 里看到的就是它。
  2. 2 邮箱（อีเมล）：填你的管理邮箱。
  3. 往下：国家选 ไทย；公司名填租户公司名；业务类型随便选一个大类和小类。
  4. 点最下面绿色的 ตกลง（同意）→ 确认页再点提交 → 完成。

A2　开通 Messaging API，拿频道 ID 和密钥，填 Webhook

  1. 回到 manager.line.biz，点进刚建的号 → 右上角 Settings。
  2. 左侧点 1 Messaging API。
  3. 新号这里会有一个 Enable Messaging API（启用）按钮：点它 → 选择开发者（Provider）选 Pearnly → 隐私政策、条款两个网址留空 → OK。
  4. 启用后就是下图的样子：2 Channel ID 和 Channel secret，各点 Copy 记下来。
  5. 3 Webhook URL 填上面生成的 Webhook 地址 ，点 Save。
Provider 一定选 Pearnly，不要新建。选错了，后面在 Developers 里找不到这个号，LIFF 也对不上。

A3　回复设置：打开 Webhooks，关掉问候语和自动回复

  1. 左侧点 1 Response settings。
  2. 2 Greeting message 关掉（灰色）。
  3. 3 Webhooks 打开（绿色）。这一步最容易漏，没开的话客户发消息系统收不到。
  1. 往下 Response method 选 1 Manual chat（不要选带 auto-response 的），否则客户会同时收到官方号的自动回复和系统的回复。

BLINE Developers：打开重投、发长期令牌

网址 developers.line.biz/console，同一个账号。

B1　找到这个号的频道

  1. 左侧 1 Providers 下点 Pearnly。
  2. 点 2 新号的卡片（名字就是 A1 填的账号名称，下面写着 Messaging API）。

B2　（核对）频道 ID 和密钥

A2 已经拿到的话可以跳过。1 Basic settings 标签里 2 Channel ID；往下滚是 Channel secret。

B3　Messaging API 标签：核对 Webhook，打开两个开关

  1. 点 1 Messaging API 标签；2 Bot basic ID（@开头）就是客户搜索加好友用的号。
  1. 往下到 Webhook settings：1 Webhook URL 应该就是你在 A2 填的地址 。
  2. 2 Use webhook 打开（和 A3 的 Webhooks 是同一个开关，两边哪边开都行）。
  3. 3 Webhook redelivery 打开：会弹一个说明框，勾上 I've read and understood the above → 点 Enable Webhook redelivery。

地址不对的话点 Edit，1 改成正确地址 → 2 Update。旁边的 Verify 在开户完成之前会失败，属正常，不用管。

  1. 同一页再往下的 LINE Official Account features：1 Auto-reply messages 如果是 Enabled，说明 A3 的 Response method 没选对，回去改成 Manual chat。

B4　发长期访问令牌

  1. Messaging API 标签拉到最底：Channel access token (long-lived)。
  2. 新号这里是 Issue 按钮：点一次，出来一长串令牌，点旁边小图标复制。
已经在用的号千万不要点 Reissue：旧令牌会立刻失效，那个租户的 LINE 马上发不出消息。只有新号才点 Issue。

C建 LIFF（LINE 免密登录要用）

LIFF 建在全平台共用的 Pearnly 频道下（LINE Login 类型、猫咪头像），不是建在新号自己的频道里。每个租户建一个。

C1　打开共用频道的 LIFF 标签

  1. Developers → Providers → Pearnly → 点名字叫 Pearnly、标着 LINE Login 的那张卡片。
  2. 点 1 LIFF 标签 → 2 Add。

C2　填 LIFF 表单

  1. 1 LIFF app name：填域名前缀，例如 。
  1. 1 Size 选 Full。
  2. 2 Endpoint URL：ERP / Cowork 填 ；DMS 填 。
  3. 3 Scopes 勾 openid 和 profile（chat_message.write 不勾）。
  1. 1 Add friend option 选 Off；Scan QR 不用开。
  2. 点 2 Add。

C3　复制 LIFF ID

回到 LIFF 列表，找到刚建的那一行，1 复制 LIFF ID。

LIFF ID 必须以 2010411313- 开头。不是这个开头，说明建错了频道，LINE 免密登录不会开。

D开户后台：填单、发号并开通

本机管理后台 control.localhost:8104 → 发号单。

D1　新建发号单

点右上 1 + 添加Pearnly Issue。

D2　填基础信息和产品行

  1. 1 公司名称、用户名、邮箱、初始密码（都必填）；欢迎邮件语言默认泰文。
  2. 2 产品与域名这一行：选产品，填域名前缀 。
  3. 点这一行最右边的 3 铅笔，打开整行编辑（LINE 的几格在表格里显示不全，要在这里填）。

D3　在整行编辑里填 LINE 四个值

  1. 上半部分：1 产品、2 域名前缀（只填前缀，访问域名会自动出来）、3 界面标题（可以留空，留空用公司名）。
  1. 往下 LINE 渠道：1 依次填 LINE 渠道 ID、LINE LIFF ID、LINE 渠道密钥、LINE 渠道访问令牌。
  2. 四个值要么全填，要么全空；只填一半会被拒绝保存。
  3. 填完按 Esc 或点空白处关闭这个窗口。

D4　发号并开通，看进度

  1. 点右上 发号并开通（D2 截图里的 4）。
  2. 开通自动进行，点 查看进度 能看到每一步，全部完成大约几分钟。
  3. 1 配 LINE 渠道 这一步会自动设置 Webhook 地址、发布 LINE 菜单、开免密登录。
  4. 2 标记开通完成 是最后检查。如果这一步失败，最常见的原因是 A3 / B3 的 Webhook 开关没开：打开后在发号单上点重试开通。
第 3、4 条的自动设置和检查，要等 2026-09-30 合入的开户改动部署上线后才生效。部署前开的租户：Webhook 照 A2 手填即可；LINE 菜单和 Cowork 免密登录需要部署后重新执行一次"配 LINE 渠道"。

E开完 2 分钟自测

最容易出错的 5 个地方

  1. 开 Messaging API 时 Provider 没选 Pearnly。
  2. Webhook 开关没开（A3 的 Webhooks 或 B3 的 Use webhook，二者是同一个）。
  3. 给已经在用的号点了 Reissue，那个租户的 LINE 立刻断。
  4. LIFF 建到了新号自己的频道里，而不是共用的 Pearnly（LINE Login）频道。
  5. Webhook 地址、LIFF 地址里的前缀和开户单的域名前缀不一致。
