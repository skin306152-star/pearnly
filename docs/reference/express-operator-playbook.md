# Express 代录操作手册（初稿）

**来源**：验收窗口 2026-10-25 在测试机（lenovo-office-lan）上远程操作服务器版 Express，在服务器测试账套 `\\accserver\d$\account\70EXP\test` 亲手录单的实录。
- 公司列表里叫「9.ข้อมูลทดสอบเวอร์ชั่น 1」，代码 DATAT，路径 TEST。
- 每一步录前、录后整本拷贝，按 DBF 原始字节逐表比对，所以下面写的落库都是实测。
- 落库细节和消息号总表见《Express 原生规则参考》（`docs/work/2026-10-25-express-native-rules.md`）。本手册只讲「怎么操作」。

**用途**：将来「CC 套壳 Claude，真实打开 Express 按单代录」的第一手材料，也是人工代录的照做清单。

**版本**：ExpressI.exe **1.0.1.94**（Internal），S/N W-10T-260123，DB_ver 1.94；程序跑在 `\\Accserver\d$\ACCOUNT\70EXP\ExpressI.exe`。

**环境**：
- 屏幕 1920×1080；
- 系统区域泰文（ANSI 874）；
- 操作账号是测试机的 Windows 用户 skin3；
- Express 登录由人本人输密码。

> 坐标都是 1920×1080 下**窗口最大化**后的位置，只作参考。窗口不最大化时每开一次会层叠错开，位置不同。**每一步先截图再点**，不要凭记忆坐标连点。

## 0. 通用做法

### 0.1 远程操作的基本循环（脚本见 `scripts/express-operator/`）
1. 动作写成 JSON 清单：activate、keys、click、paste、wait、shot。
2. 用 `xprun.sh` 推到测试机，以登录用户的交互会话执行 `express-ui.ps1`。
3. 每次按键 / 点击前，脚本核前台窗口是 ExpressI，不是就中止。
4. 拉回截图看画面，再写下一批动作。一批只做一小段（一个字段到一个弹窗为止），看到弹窗再决定按什么。

### 0.2 进入账套
1. 人在桌面「ExpressI」快捷方式启动服务器版 Express，并**亲手输密码登录**。程序不输、也不找密码。
2. 公司列表：点「รหัส」表头按代码排序；点 **ค้นหา**，在框里输代码，点确定。
3. **点 ตกลง 前截图，确认选中的行**（名字 / 代码 / 路径都对）。
4. 「วันที่ทำการ」（工作日）框点确定。进账套后状态栏显示「บริษัท … (\\Accserver\d$\ACCOUNT\70EXP\TEST) by BIT9」。
- 耗时：开账套约 3 秒，确认日期约 3 秒。

### 0.3 菜单与通用按键
- 主菜单 **Alt+1 … Alt+8**：1.ซื้อ / 2.ขาย / 3.การเงิน / 4.สินค้า / 5.บัญชี / 6.รายงาน / 7.เริ่มระบบ / 8.อื่นๆ。之后按数字选子项。
  - **菜单要在同一次脚本里连按完**：新开的脚本进程会抢一次焦点，已经展开的菜单会收起。
- 打开单据窗口约 **5–6 秒**。打开后先最大化（窗口右上「□」），坐标才固定。
- 单据工具栏从左到右：新建、编辑、作废（红章）、删除、**取消（⊗）**、**保存（软盘）**、上一张 / 下一张、查找……
  - 最大化后：新建 ≈ (35,103)、编辑 ≈ (80,103)、取消 ≈ (229,103)、保存 ≈ (274,103)。
- 明细表格：输品码 → **回车**带出品名、跳到「คลัง」（仓）→ 回车 → 数量 → 回车 → 弹「单位」框（ตกลง）→ 单价 → 回车 → 折扣 → 回车 → 金额 → 回车，这一行结束，开下一行。
  - 最后多出的空行按 **Esc** 退掉再保存。
- 关闭单据窗口：最大化后点主窗口最右上的那个小「×」（菜单栏右边）。注意别点成还原键：会弹 Message 40，点 ตกลง 即可，无害。

### 0.4 输入格式
- 日期 `25/10/69`（日 / 月 / 佛历年后两位）。
- 数字直接打，不带千分位。
- 英文编码、数字用 SendKeys。
- **泰文**用剪贴板：先 LoadKeyboardLayout 泰文，再 SetText，再 **Shift+Insert**。Ctrl+V 无效；直接 SendKeys 泰文会变成「????」或乱码。

### 0.5 确认保存成功
- 画面：单号从「前缀NEW」变成正式号；工具栏回到浏览态（新建 / 编辑亮、保存灰）。
- 库里：拷账套副本，查 ARTRN（销项）/ APTRN（进项）/ STTRN（库存单）有这张单号，STCRD 有明细，GLJNL / GLJNLIT 有凭证，ISRUN 该前缀 +1。

## 1. 赊购 RR（ซื้อเงินเชื่อ）
- 路径：Alt+1 → 4。
- 步骤（最大化后）：
  1. 新建；
  2. 供应商码（例 P001）回车，带出名称地址；
  3. 「เลขที่บิล」供应商单号；
  4. 「ลงวันที่」= 单据日期；
  5. 明细：品码 → 回车 → 仓（默认 01，要改就 Home+Shift+End 后输仓码）→ 回车 → 数量 → 回车 → 「ป้อนหน่วยนับที่ซื้อ」单位框 ตกลง → 单价 → 回车 ×3 → Esc → 保存。
- 弹窗：只有单位框。
- 耗时约 1 分钟。
- 落库：APTRN、STCRD（MLOTNUM「B/F」批次）、STLOC（该仓没有行会新建）、STMAS、GL、ISVAT（P）、APMAS / APBAL。
- **存进货单时会回填之前负库存销售的成本。**

## 2. 现购 HP（ซื้อเงินสด-ทั่วไป），含转账付款
- 路径：Alt+1 → 2 → 1。另有 2「ซื้อโดยโอนผ่าน TMB」专门类型。
- 录法同赊购。**保存时不弹付款框，默认全额现金**。
- 改付款方式：编辑 →「รายการจ่ายชำระ <F7>」页签 → **双击**「ชำระโดยอื่นๆ」第一格 → 付款类型清单（截图 `express-operator-playbook/pay-types-list.png`）→ 选类型（例 TA）→ ตกลง。
  - **参考号自动填「类型码 + 单号」**（TAHP0000006，截图 `pay-autoref-TAHP.png`）；回车，金额自动填应付余额，「จ่ายด้วยเงินสด」变 0；保存。
  - 第二种付款：上一行回车后自动开第二行并弹类型清单（这一步还没录完，见「踩过的坑 6」）。
- 注意：
  - 在明细格里按 F7 会打开商品查找 / 行备注，不是付款页。要先 Esc 离开表格，再点页签。
  - 编辑时「หักเงินมัดจำ」（扣订金）栏会自己出现「AE」，存后 APTRN.ADVNUM='AE'。
- 落库：APRCPCQ 新增；APTRN CSHPAY→0、CHQPAY / CHQPAS = 金额；凭证贷付款类型科目；**BKTRN 不写**。

## 3. 赊销 IV（ขายเงินเชื่อ）
- 路径：Alt+2 → 4。
- 步骤：新建 → 客户码回车 → 明细（品码 → 回车 → 仓 → 回车 → 数量 → 回车 → 单位框 ตกลง → 单价 → 回车 ×3）→ Esc → 保存。
- 弹窗：
  - **4079**「客户没买过此品，要自己填价」：ตกลง，光标进单价格。
  - **4107**「客户价格表为 0，取最近售价」：ตกลง。
  - 负库存相关见第 12 节。
- 耗时约 1 分钟。

## 4. 现销 HS（ขายเงินสด-หน้าลาน）
- 路径：Alt+2 → 2 → 1。录法同赊销；价格类型默认「1-รวม VAT」（含税）。
- 保存默认全额现金（ARTRN CSHRCV）。
- **收非现金**：付款页双击「ชำระโดยอื่นๆ」，有收款类型清单（截图 `express-operator-playbook/receive-types-list.png`）。
  - 选 VS / QR 等以后，回车或点金额，弹的是「**选已登记支票 / 收款**」清单（截图 `express-operator-playbook/receive-cheque-lookup.png`）。
  - **不会像付款端那样自动生成参考号**。
  - 要先在「3.การเงิน」下登记收票 / 刷卡，才能在 HS 里挂上（尚未实录）。
- 进编辑再取消，ARTRN.ADVNUM 也会被写成「AI」。

## 5. 领用 OU（จ่ายสินค้าใช้ภายใน）

- 新建 → 备注（泰文用剪贴板）→ 明细品码 → 仓 → 数量 → 单位框 → 成本自动带 → 保存。
- 落库：STTRN（POSOPR 6）、STCRD、GLJNL（00）2 行。

## 7. 退货 SR（ใบลดหนี้/รับคืนสินค้า）
- 路径：Alt+3 → 1 → 4（在「การเงิน → รับเงิน」下，不在「ขาย」下）。
- 步骤：
  1. 新建 → 客户码；
  2. 「เลขที่ใบกำกับ」改成原单号（默认带「IV」前缀，要 Home+Shift+End 清掉）→ 回车；
  3. 弹 **4629**（退货日不晚于原单，可能影响成本）：ตกลง；
  4. 弹原税票金额框：ตกลง；
  5. 明细品码回车，弹「退货明细」框（截图 `express-operator-playbook/return-line-dialog.png`）：
     - รับคืนสินค้า：Y = 回仓，N = 只减价；
     - เข้าคลัง：回哪个仓；
     - 数量；
     - **金额要手改**（改数量不会重算）；
     - รับของแถมคืน；
     - 填完点 ตกลง。
  6. 勾选原单行 → **ทำงาน <F5>**；
  7. 二选一（截图 `express-operator-playbook/return-refund-choice.png`）：「จ่ายคืนเป็นเงินสด」（当场退现金）/「เก็บไว้หักตอนรับชำระหนี้」（留着抵下次收款）。选完直接存好。
- 耗时约 2 分钟。「只减价」「留着抵」两种待实录。

## 8. 仓间调拨 RL（โอนย้ายระหว่างคลัง）
- 路径：Alt+4 → 1 → 2。
- 首次打开弹 **2810**（RL 没设日记账），保存弹 **43**：都点 ตกลง。
- 新建 → 来源仓（默认带 01，要改先 Home+Shift+End 清空再输）→ 回车 → 目的仓 → 回车 → 说明 → 回车 → 品码 → 回车 → 数量 → 回车 → 单位框 ตกลง → 弹 43 点 ตกลง → 光标到下一行；多行照此继续，最后 Esc 退掉空行 → 保存。
- 明细没有价格栏。目的仓里原来没有这件商品也能调，Express 会给目的仓新建 STLOC 行。
- 作废：同第 9 节，一次确认后弹 43，点 ตกลง。
- 落库：每件一对 STCRD（POSOPR 4 / 3）+ STTRN 一行，不写 GL；逐字段见原生规则参考 4.6b。
- 耗时：两行一张约 3 分钟（含每步截图）。

## 8b. 单据行下的附加说明（车架号 / 序列号等）
- 明细行录完、点选那一行 → 工具栏「Note」→「ป้อนหมายเหตุเพิ่มเติม」框（截图 `express-operator-playbook/line-remark-dialog.png`）→ 每格一条，回车换下一格，一行最多 10 条、每条 50 字符 → ตกลง → 再点下一行、再 Note → 全部录完再保存。
- **存档前录**；存完再「编辑 → Note」改说明不会落库。
- 光标在单头时 Note 是灰的。
- 赊购 RR 单头的「หมายเหตุ」栏是另一回事：它写进 APTRN.YOUREF，打在单头（截图 `express-operator-playbook/rr-header-remark.png`）。
- 屏幕预览：Alt+P → 选「จอภาพ」→ ตกลง。说明印在商品行正下方（截图 `express-operator-playbook/iv-print-line-remarks.png`）。预览不写账套，右上「×」关闭。
  - 表单 1 这一栏约放 40 个字符，超过会压线。

## 9. 作废
- 打开那张单 → 工具栏第 3 个（红章）→ 一次确认「กรุณาเลือกตกลง เพื่อยืนยันให้ยกเลิกเอกสาร」（截图 `express-operator-playbook/void-confirm.png`）→ ตกลง。不要原因，不要密码。
- 画面红字「ถูกยกเลิก」，单号保留，明细清空。
- 已实录 IV、OU、RL（10-26，RL 作废后再弹一次 43）；RR / HP / HS / JU 待实录（第 8 条）。

## 12. 负库存会看到什么（判定规则见原生规则参考）
| 情形 | 弹窗 | 怎么办 |
|---|---|---|
| 账套 N / 1–2，或商品 N 且账套 1–2：该仓会变负 | 录行弹 **4224**「ยอดคงเหลือของสินค้าติดลบ」（截图 `express-operator-playbook/msg-4224-neg-stock-block.png`） | 行进不去，光标回数量格。这一单要放弃：Esc，再取消。存档会留一张金额 0 的空单头、占一个单号 |
| 账套 N / 0，或商品 N 且账套 0：全仓合计不够 | 行完成 / 保存时弹 **4091**「ยอดสินค้าติดลบ รหัสสินค้า[…] คลัง[…]」（截图 `express-operator-playbook/msg-4091-neg-stock-on-save.png`） | 同上，那一行被丢掉 |
| 商品 Y | **605**「ยอดสินค้าคงเหลือติดลบ」（截图 `express-operator-playbook/msg-605-neg-stock-warning.png`） | 只是提醒，ตกลง 后照常录、照存 |

另：录行时仓库下拉只列「这个品已有库存记录」的仓，手输别的仓不被接受。

## 13. 踩过的坑
1. **泰文输入**：SendKeys 打不出泰文。用剪贴板 + Shift+Insert，粘贴前在发键线程里 LoadKeyboardLayout('0000041E')。Ctrl+V 在 Express 里无效。
2. **前台被抢**：别的窗口跳到前台时，按键会打错地方，例如别人以可见窗口跑的 python、Windows 设置。
   - 脚本每次按键前核前台是 ExpressI，不是就中止。
   - 同机其他人的后台程序一律隐藏窗口（pythonw / -WindowStyle Hidden）。
   - 计划任务名别和别人共用，会互相注销。
3. **SMB 会话断开 → Express 崩溃**：
   - 程序本身跑在 `\\Accserver` 网络共享上。网络会话一断，下一次读文件就报 **Error -70 (90621) Reading File …\STMAS.CDX / ISRUN.CDX**（截图 `express-operator-playbook/err-70-smb-read.png`）。
   - 点确定后 ExpressI 以 **0xc0000006**（从网络盘换页失败）崩溃退出。账套没被写坏（前后比对零改动），但未存的编辑丢失。
   - 已见原因：
     - 18:2x 会话中断，时间上和别人的 lab-stop / 清 DNS / 重启 CC 重合；
     - **accserver 晚上下线**（20:32，445 端口不通、名字解析不了）。
   - 规矩：Express 开着时，谁要动网络 / DNS / CC / 实验栈，先在占用表登记并通知操作者；每次录单前先空读一次确认会话正常。看到 -70 **先别点**，查网络。
4. **C 盘本机 Express 一开单据就报 -330 ISRUN1–4**：
   - 不是数据问题，是 Express 的防拷贝授权绑在服务器上，C 盘这套没有授权。
   - 不改数据、不绕过；只能用服务器版，或向厂商要本机授权。
5. **被拦后留空单头占号**：被负库存拦下的单，存档时仍写一张金额 0 的 ARTRN 单头，ISRUN +1。中途写的明细会打删除标记回滚。所以「被拦」≠「什么都没写」。
6. **按回车 / 取消也会存**：明细最后一行完成后再回车会开新行；在某些状态下按 Esc 或「取消」会直接存档（IV0000038、IV0000034 就是这样存下的）。**每一步截图确认状态再按下一键**；不想存的单要先清空明细。
7. **进编辑就写 ADVNUM**：HP 进编辑出现「AE」、HS 出现「AI」。即使取消编辑也写进 ARTRN / APTRN.ADVNUM（金额 0）。Express 自身现象，CC 不照抄。
8. **登录要人输密码**：程序不输、不找、不存密码。崩溃或下线后要人重新登录。
9. **窗口层叠**：不最大化时每开一次窗口位置都变；先最大化再操作。还原键误点弹 Message 40，无害。
10. **收款端非现金**不能当场录（见第 4 节），要先登记收票。

## 14. 耗时参考（远程，含截图往返）
- 进账套约 10 秒。
- 打开单据窗口 5–6 秒；每个字段约 1 秒；弹窗出现约 1.5 秒；保存 2–3 秒。
- 一张一行的单从打开到保存约 1–2 分钟（含每步截图确认）。
- 整本账套拷副本约 30 秒（4 MB 级测试账套）。
- 改一次设置（打开 → 编辑 → 保存 → 确认）约 1 分钟。
