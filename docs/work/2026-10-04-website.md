# pearnly.com 官网静态站（2026-10-04）

分支 `codex/website`，基线 `origin/main` `df31c79b`。用户要一个简洁、能被谷歌搜到的宣传页。

## 起点

- pearnly.com 只有一行“建设中”（`/var/www/pearnly-landing/index.html`，源码不在仓库）；`robots.txt`、`sitemap.xml` 都 404。
- 服务器上 `/etc/nginx/conf.d/pearnly-landing.conf` 与仓库 `infrastructure/production/landing.conf` 一致（md5 相同）；服务器没有 rsync。

## 归属与边界

- 新目录 `website/`：官网静态站，与 `companion/` 同级，不属于任何 Frappe App，也不是产品 Web（产品 Web 仍是原生 Desk）。没有服务端代码、没有外部写入、不碰业务容器与数据。
- 数据流：`content.py`（文案）→ `build.py`（标准库渲染）→ `website/dist/`（不提交）→ `scripts/publish-website.sh` 一次 SSH 整目录替换，上一版留 `.prev`。
- 不新增月费：静态文件由现有 nginx 提供；视频走已有的 `media.pearnly.com`（R2，出流量免费）。

## 内容

| 页面 | 用途 | 去向 |
|---|---|---|
| `/`（+ `/en/`、`/zh/`） | 一句话说明 + 三个产品 + 三步流程 + 免费工具入口 | 产品页、工具页、LINE `@pearnly` |
| `/cowork/` | 会计事务所：录入 Express、小助手、银行/收入对账、销项税核查、任务看板 | LINE；小助手固定名安装包 |
| `/dms/` | MR.ERP DMS 的 LINE 助手：菜单 1 建客户、菜单 2 订车、名单与推送记录；嵌 3 段已公开教程 | LINE |
| `/erp/` | 商品仓库、拍票录采购、拍收据录销售、收发存、POS、LINE 盘点、团队权限 | LINE |
| `/tools/…` | 数字转泰文金额、7% VAT、预扣税、13 位税号校验（浏览器内计算） | 其他工具、首页 |

文案逐项对过代码：POS 不写“自动扣库存”（库存移动只来自出入库单）；收入对账 = 总账收入对销项税报告；销项税核查 = 报告对发票。税号校验与 `pearnly_core.tax_documents.amounts.valid_tax_id` 同一算法。预扣税率只列公司付公司的常用税率并注明以税务局为准。

SEO：每页独立标题与描述、自指 canonical、th / en / zh-Hans / x-default 互指 hreflang、Open Graph、schema.org（Organization、WebSite、SoftwareApplication、WebApplication、BreadcrumbList、DMS 三段 VideoObject）；sitemap 带多语言互指；404 页 `noindex`。nginx：www → 不带 www 301、`error_page 404`、`/static/` 缓存一周、样式脚本 gzip。
