# 扫描件与照片看图直读换 gemini-3.8-flash（2026-10-02）

用户同意：扫描件和照片的看图直读换成 3.8-flash，同时补一句「水电费账单、请款单算采购凭证」。按站点配置
`OCR_DIRECT_MODEL` 逐站打开（识别窗口负责配置与 Cloud Run），先只开 testcowork，测试租户 100 人压测（闸 ②）过了再逐站开。

## 本分支的改动

- `ocr/engine/prompts.py`：`image_system(direct_model)`，直读模型以 `gemini-3.8` 开头时在第 11 条后补
  `BILLS_ARE_PURCHASES`，否则返回原 `IMAGE_SYSTEM`。flash-lite（生产现状）的提示词一字不变。
- `ocr/engine/runner.py`：直读、带提示复核、带原文再读三处都用 `image_system(config.direct_model)`，与 eval7b 实测一致
  （已逐字核对：3.8 拿到的提示词与 eval7b 修订版 cowork-ocr-00048-yet 相同）。
