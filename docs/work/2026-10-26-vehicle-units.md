# 车辆按台管理（第 4 项，不接 Express 的完整流程）

设计（主会话 10-26 审定）：`docs/work/2026-10-26-vehicle-units-设计.md`。第 6 节决定：接了 Express 的公司也能开、车号只在 ERP；
没盘到的台不自动改状态、差异报表列出来；**已有库存的商品可以开，但要先按台期初登记**（Excel 逐台导入：号码 / 副号 / 颜色 / 仓 / 库位，
每个仓台数等于账面数，同一个事务里开），开了以后只有全部台已售或作废才能关；过账前必须登记、台数 ≠ 数量不让过账。
列表与 Excel 导入导出用服务端分页。基线 main `d8d42e6f`，分支 `pearnly/vehicle-units`。

## 做了什么

- 表：`ERP Serial No`（一台一条：车型、公司、主号 / 副号 / 颜色、状态 在库 / 已售 / 已出库 / 作废、仓 / 库位、进 / 出单据）、
  `ERP Serial Movement`（按台流水：进 / 出 / 退回 / 期初 / 盘点挪位，作废时按它反向）、`ERP Line Serial`（单据上的台，四种单共用，按行号对回明细）；
  商品加「按台管理」「号码种类（车 / 其他）」；进货、销售单、收银小票、出入库单加 `serials`；盘点记录加 `serial`。
- 规则（`inventory/serials.py`）挂在库存层唯一的汇合点：`stock.apply_lines` 落流水前核台数并登记 / 收回 / 出台，`stock.reverse_movements` 先按按台流水回退。
  进货、入库「其他」登记新台；收银退货、入库「退货」收回已售的台（收银退货只能退原小票卖出的台，没选按原小票取）；销售 / 收银改已售、出库改已出库，
  只认这个仓在库的台；作废时出的台回原仓原库位，进的台还在库就作废（不占号），有一台已卖出整单拒。盘点生成的出入库单不动台；
  期初批量导入、库存直接调整对按台商品拒收（只经带台的单据动库存）。不开按台的商品不经这里，行为不变。
- 认台：主号全等 → 副号全等 → 主号末 8 位，只认本公司没作废的；认出几台列出来让人选。
- 盘点：扫车身二维码（车架号全号）认到车型和那一台，一台一条、数量固定 1，同一份盘点重复扫拒；过账时盘到的台记到实际仓位；
  盘点录入弹窗列出这个仓在库的每一台和盘到没有（原生 DataTable）；差异报表多一列「未盘到的台」。LINE 手机盘点扫车架号同样认台。
- 页面：出入库单、进货（带入库）、销售收据、收银台提交前，按台商品逐行弹「登记车辆 / 选择车辆」（原生 Dialog + Table，号码可扫码；
  选台是原生 Link，下拉走服务端分页搜索），取消就不提交。商品页：勾「按台管理」时没有库存直接开，有库存弹「按台期初登记」
  （各仓账面数、下载模板、上传 Excel）；「按台记录」列表（服务端分页、按状态 / 号码筛、导出 Excel）。

## 验收复核修正（10-26，「车辆-库位-内部编码-复核-10-26.md」）

- 【高】作废出库 / 销售时核这台车现在仍是这张单出的（已售或已出库、出库单号就是这张），否则整单拒：出库后经入库「退货」收回、再作废出库单不会多出一台。
- 【高】盘点扫到别处（别的仓，或这个仓里没盘的那一行）的车（主会话口径）：照样记在实际盘到的地方，过账时原处减 1、实际处加 1，
  台的仓 / 库位跟着改，数量与台数两边对得上（`count._unit_sources`）。原来过账后车记到这个仓、原仓账面数没减。
- 【高】按台记录进菜单权限目录（`access/menu.py` 的 `SERIALS`，商品、库存、出入库、盘点、采购、销售、收银、收据菜单都可读），
  读权限任一开单 / 看库存的能力都算（仍按仓）：ERP 用户原来打开按台记录、选车下拉报 403。
- 【中】认车：输入 17 位完整车架号只认完全一样的，找不到报「该台不存在」；输入正好 8 位才按末 8 位认；发动机号照旧全等。
- 静态几条：收银部分退（卖了几台只退一部分）要选退哪几台，不默认挑；两处退货界面接上选车，只列原小票卖出的车；
  入库「退货」可选已售或已出库的车；恢复作废的盘点记录时这一台已另记过就拒；开按台拿商品锁；按台期初看库存只报本人看得到的仓的名称。
