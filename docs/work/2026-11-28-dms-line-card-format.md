# DMS LINE 卡片两处显示：时间用冒号、赠品一行

分支 `pearnly/dms-line-card-format`，基线 `origin/main` 568f4b7f6（= 线上）。显示修复，不改入口、权限、词条。

## 用户反馈（11-28，线上 ris 的 LINE）

1. 库存停放报表卡片副标题「98 คัน · 28/11/2026 07.49」。用户原话：「时间格式不对，应该是：不是 .」
2. 订车「确认前汇总」卡片（สรุปใบจอง — ตรวจสอบก่อนยืนยัน）的赠品清单（รายการของแถม）每件占两行（名称一行、数量另起一行靠右），太占位置。

## 改动

- `query/stock_render.as_of_label`：时与分之间四语都用冒号（原先泰文照 11-26 样表用点）。卡片副标题、下载页标题行、汇总图 / PDF / Excel 底部「อัพเดต … เวลา 07:49 Total」都取这里，一处改全改。按类查：DMS 发到 LINE 的其它时间（查询卡片 `query_cards` 的 `%d/%m/%Y %H:%M`）本来就是冒号；文件名里的时间戳没有分隔符，不动。
  这是改已有输出，但改的是代码里的分隔符、不是词条，`check-copy.py` 不登记（无对应键）；用户原话记在本记录。
- `booking/conversation/qa_cards.freebie_rows`：只有「数量 单位」时（车型主档默认不显示价格，用户截图就是这种）每件赠品一行——横排，名称 `flex 1` 可在本格折行，数量 `flex 0` 靠右贴顶、不折行，名称再长也不把数量挤到下一行。
  **显示价格时保留原两行**：「1 ชุด × 14,234.13 = 14,234.13」这种算式放同一行会被拆成两三行（出图核过），比原来更难读，原代码注释写的正是「窄屏不拆开算式」。卡片里其它「左标签右值」行不动。
  按类查：赠品逐行清单只在确认前汇总卡；确认后的核对（`booking_review`）是「提交值 vs DMS 值」逗号连成一行的差异对照，不是同一种清单，不动。
