# 开发工作包

这里保存本仓开发任务的范围、决定、证据和交接，不作为产品功能或新的需求池。

- 命名：`YYYY-MM-DD-topic.md`，同一工作包后续更新原文件。
- 模板：[工作包](../development/templates/work-package.md)；要求见 [记录规范](../development/records.md)。
- 小修可以只写提交/PR；长任务和迁移必须有能续接的记录。
- 旧 `docs/p0` 至 `docs/p4` 保留作历史，不重新搬运，也不把旧 TODO 自动加入新任务。
- 此索引不要求逐条登记所有工作包，避免多个窗口编辑同一份任务总表。
