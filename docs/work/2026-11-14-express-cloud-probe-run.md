## 3. 云端这一列最终要支持的格（用户 11-14 范围）与依赖、施工量

用户 11-14：代录只做采购、销售（各类票都要覆盖）× 本地 / 云端 Express / MR.ERP；收款只在 ERP、只做直写；其它业务只做直写。所以云端这一列是 4 格：

| 格 | 业务 | 依赖哪几项实测 | 在共用底座之上还要做的 | 施工量（机器耗时） |
| --- | --- | --- | --- | --- |
| Cowork × 直写 | 进项 / 销项 / 费用等现有直写业务 | T2（会话照跑、隧道照通）、T3（后台重连不要密码）、T4（保活）、T5（怎么启动、整包拷多久）、T6（CC 与 CDX 索引程序能跑） | 无新写法；Z1 上每类单真写一张 + 读回 | 约 1 小时（真写验收） |
| ERP × 直写 | 采购、销售、收款（只 ERP）、库存 / POS / 定时等其它直写 | 同上 | 同上；收款按 RE 读回 | 约 1.5 小时 |
| Cowork × 代录 | 采购、销售各类票（赊 / 现、货品 / 费用 / 服务、含税 / 无税、带折扣） | 上面全部 + T2 的「还在画」（截图不是整片一色）+ T3 的「第二个 Express 占不占名额」 | 代录在云端会话里开 Express（后台做法）；Express 登录凭据经隧道交给云端、只放内存；证据截图经隧道交回；有人在用这个会话就排队 | 约 2.5 小时（含 Z1 上各类票各一张） |
| ERP × 代录 | 同上 | 同上 | 同上（与 Cowork 同一套，只多验一遍） | 约 1.5 小时 |

- **共用底座**（4 格都靠它，评估第 13 节第 1–6 步）：统一建联网客户端 → 文件隧道（签名、白名单、超时）→ 云端模式 `--cloud` → 桥的会话管理（隐藏桌面、重连、被挤标记）→ 配对代登记 →
  设置页「云端 Express」一行 + 四语文案 + 产品地图。按机器耗时：**写代码约 12–16 小时 + 检查 / 打包约 5 小时**；之后 4 格真写验收合计约 6–7 小时（桥电脑开着即可，不用人）。
- 用户只需：在 CC 设置里点「连接云端 Express」时输一次云端密码（约 5 分钟）；代录要 Express 登录时再输一次。
- 实测结果会改变的地方：T2 不过要换 RDP 控件宿主（+3–4 小时）；T5 登录即运行不通要走「授权时打一行命令」（+1 小时）；T3 一账号一会话要做「被挤标记」（已在评估里，+1 小时）；
  T6 不过或 T3 卡登录框 = 这条路不通，停下重评。

## 4. 11-15 实测记录（测试机1，21:00–23:25；证据在 `~/pearnly-devtools/express-cloud-probe-1115/evidence/`）

用户 20:35 先用 TSplus 自己连过一次（Session.rdp：198.51.100.7、端口 3390、域 example、不校验证书）。T6 在用户被告知「在服务商服务器上运行未签名程序」的风险、回复「跑」之后才执行。

| 项 | 结果 | 证据 |
| --- | --- | --- |
| T1 直接用 mstsc 登录 | **通过** | 我们的 .rdp 照 TSplus 写法（主机、端口分开写，`username:s:CLOUDUSER-01` + `domain:s:example`），用户在 Windows 框里输一次密码后连上。之前没写用户名时，用户连输 7 次都失败（原因码 2055 = 用户名不对）。TSplus 存的旧式凭据（LegacyGeneric），开着网络级身份验证的连接用不上；关掉网络级身份验证又不送账号，云端停在登录界面约 30 秒后断开 |
| T5 云端怎么跑起来 | **通过（只有一条路）** | 只有「点云端开始菜单 → 打 powershell → 打命令」能启动。Win+R 打不进去；`.rdp` 里的「登录即运行」新登录时也不生效（23:16，会话 1688）。可写：用户目录、临时目录、启动文件夹；D: 根目录不可写；C: 剩 21 GB。拷贝：100 MB 用 53 秒（≈1.9 MB/s），ccprobe 20 MB 用 12 秒，CC 整包 586 MB 用 954 秒（期间测试机在跑 runner） |
| T3 同账号 / 后台重连 / 名额 | **通过（规则据此定）** | 同账号只有一个会话（1687），后连的接管先连的，两个方向一样；被挤的一端断开原因码 3，弹框原文「你已断开连接，因为已与远程计算机建立了另一个连接。」。后台重连用已存的凭据，不弹框。第二个 Express 能开到登录框、没提示名额；名额要登录才算，只读不登录，**没测到** |
| T2 隐藏后照跑照画 | **通过** | 隐藏桌面上的会话 21:13–23:15 心跳不断（共 252 次）。每 5 分钟一轮截图（探针窗口、记事本、Express、整屏）都不是整片一色，隧道一直通 |
| T4 空闲断开 / 桥资源 | **通过** | 空闲 7326 秒仍是 Active，服务器没有空闲断开，不需要保活。桥上 mstsc：每分钟约 1 秒 CPU（探针每秒刷新时钟时，约 1.5% 单核），内存约 240 MB（专用约 370 MB）；拷贝时更高 |
