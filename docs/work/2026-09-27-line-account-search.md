# 账套上传前由用户选：LINE 打字找账套 + 推送前防错（2026-09-27）

分支 `codex/line-account-search`，基线 main 48191a83。用户 2026-09-27：「系统无法自动判断的由用户预先选择兜底，按用户的选择执行，
减少推错和自动匹配」；「网页端是先选择，LINE 端先输入词匹配，编辑页不再提供选择」。

## 改动

| 位置 | 内容 |
|---|---|
| LINE | 目标 → **账套** → 进项 / 销项 → 入账方式。账套这一步：目录里只有一份就直接选上；否则请用户打几个字（账套名、公司名、年度文件夹、税号都认，几个词都要有），列出匹配结果全名、按钮只放序号（LINE 按钮字数上限 20），最多 11 个，多了提示再多打几个字；另给「上次用的」一键选（本人在这条连接最近一次用的、还在目录里的）。打的字由 `line/handlers.py` 交给 `flow.search`。目录还没有就申请读一次、请用户稍后再点菜单。 |
| 查找 | 纯函数 `connections/account_search.py`（LINE 域只能依赖连接域）。 |
| 网页 | 不变：新建录入弹窗先选年度 / 账套。 |
| 编辑页 | 不再选账套（撤掉上一步加的「年度 / 账套」）；推到 ERP 的票没记账套时提交照旧拦下，不按连接默认账套猜。 |
| 自动挑 | 撤掉：识别后挑账套的钩子、编辑页改账套接口都删除。 |
| 推送前防错 | `targets/account_match.conflict`：Express 用户选的账套与票面**确定**对不上才拦——票上本方税号是校验位正确的 13 位且与账套税号不同；单据日期落在账套本年起 ~ 次年止之外。读不出 / 账套没报（小助手 1.2.1 没有期间）都不拦。分店号无校验位、不拿来拦。 |
| 卡片 | 目标一行只写 ERP 名，账套另起一行（票上记的）。 |
