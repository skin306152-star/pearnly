# 收款「只列收钱类」按类放宽：统计与判据（2026-11-12）

分支 `pearnly/collection-transfer-rule`（从 `origin/pearnly/collection-cc-chat` `71fe3fb2e` 开）。主会话定：以收款类型关联的科目
属于银行存款类为准，名称只作辅助；先统计证明不漏不误，再改。

## 结论

- 判据（只用账套自身结构，不靠泰文名字）：CC 按 GLACC 的 `PARENT`、BKMAS 的科目、ISINFO.ACCNUM00 给每种收款类型报
  `account_class`（`bank` / `cash_group` / `cash` / `other`），服务端 `bank` 判转账；`cash_group` 只在名称含「โอนเข้าบัญชี」时判转账
  （名称辅助）；支票、预扣、折扣的名称规则仍在前面先判。老版 CC 不报这一栏 → 服务端照旧按名称规则。
- 101 本离线测试账套（测试机 `C:\PearnlyExpress\70EXP` 下全部带 ISRUN 的子目录：T7×37、T8×41、T9×22、`dat`，约 54 家公司按年度复制）
  + NLTTEST、69EXP\TEST 两份本机只读副本，共 1961 行 ZR 收款类型：
  - 能列的转账从 159 行增到 382 行（多 229 行、分布在 55 本账套）；一种转账都没有的账套从 58 本降到 20 本，剩下 20 本里每本的转账
    类型（模板行「เงินโอนเข้าบัญชี (NBD)」）都没有科目，属账套本身没有可用的转账方式。
  - 少了 6 行：GISP/GIZP 三个年度的「เงินโอนเข้าบัญชี GIZE / GISS」，科目 1210-01 是关联公司借款（组外），名称说转账但钱不进银行——
    改为不列，合理。
  - 其余 1726 行判定不变（转账 153、支票 126、预扣 237、折扣 99、现金 95、不列 954、无科目 62）。
  - NLTTEST 30 行与现行完全一致；69EXP\TEST 的 CQ / SC / 23 三种储蓄存款判转账。

## 「银行存款类」判据

GLACC 字段：`ACCNUM ACCNAM ACCNAM2 LEVEL PARENT GROUP ACCTYP USEDEP USEJOB NATURE CONSOL STATUS …`，101 本都有 `PARENT`。

1. **现金组 G**：现金科目（ISINFO.ACCNUM00）往上找，第一个底下有 BKMAS 科目（现金科目本身不算）的上级；BKMAS 没有组内科目就取现金
   科目的上级。实测 101 本 G 全是「เงินสดและเงินฝากธนาคาร」（1110-00 / 11-01-00-00 / 110100）。现金挂在「เงินสด」小计下的
   （GIS/GIZ/SPP/TLC 现金 1111-01 → 1111-00 → 1110-00）也找到 1110-00。
2. `cash`：现金科目本身。
3. `bank`：G 之下、不是现金科目，且（在 BKMAS 里，或挂在 G 下的分组里——上级不是 G 本身、也不在现金那一支）。即 1112-00 活期、
   1113-00 储蓄、1114-00 定期、11-01-05-00 存款暂记这类分组底下的科目都算，BKMAS 漏登的存款也能认出（EXCP / NIEXCP / SUPPER
   的「เงินโอนเข้ากระแส-กสิกร / นครหลวง」、SSLAB、PREMIU 都是这种）。
4. `cash_group`：G 之下其余的——直接挂在 G 下又不在 BKMAS 的零用金、另一个现金科目（实测 13 行：เงินสดย่อย 8、另一个「รับเงินสด」科目 5）。
5. `other`：G 之外的一切，**BKMAS 里登了也一样**。

为什么不用「科目在 BKMAS 里」或「与 BKMAS 某科目同一上级」：BKMAS 在真账套里不只登存款——实测登了现金（T7ASC 1111-00、
T7SKPER、T7SPP112）、零用金（T7TSDV12 11-01-01-00）、金融机构借款（T7ASC 2300-08）、董事借款（T7TSDV12、T7PAISAR）、退票应收
（T7SKPER 1130-06、T7TSDV12 11-02-07-00）、进项税（T7GIZP 1154-01）、预扣应付（T7TUCL20 2132-02/03）、对董事放款（T7PROPHA、
T7TUCL20 1220-xx）。只看 BKMAS 会把这些判成转账；「同一上级」会把 1110-00 下的零用金、2300-00 下的借款一起拉进来。限定在现金组 G
之内、再按分组判，两种误判都排除。

判不出结构（没有 GLACC、没有 PARENT 栏、没有现金科目或它不在科目表里）CC 不报 `account_class`，服务端退回名称规则。

## 不漏（真存款类型都判成转账）

- 新判转账的 382 行科目上级全在存款分组：เงินฝากออมทรัพย์ 207、เงินฝากกระแสรายวัน 138、G 直属且在 BKMAS 30（WNF 三个年度）、
  เงินฝากประจำ 5、บัญชีพักเงินฝากธนาคาร 2。
- 辅助核对：科目名或上级名含 เงินฝาก / ธนาคาร / bank / S/A / C/A / SAVING / CURRENT、却没判转账的行逐条看过，全是该排除的：

  现金 / 零用金 / 现金待存（上级「เงินสดและเงินฝากธนาคาร」）、手续费「ค่าธรรมเนียมการโอน / ธนาคาร」（费用科目）、
  「ADVANCE ANSUS BANK」「MD K BANK」（负债：董事垫款）、「ภาษีถูกหัก ณ ที่จ่าย(KBANK 3%)」这类预扣。

## 主会话决定（11-12）

挂在存款分组下的暂记 / 垫款科目那 19 行（如「บัญชีพัก FOOD PANDA」「ADVANCE YING BBL」）**不排除**：它们是客户自己在 Express 里建的收款类型，Express 让选，我们按账套结构判进来就列出来，不再靠名称另筛（按类通用；Express 不拦我们不拦）。随新版 CC 发；老版 CC 不报 `account_class`，照旧按名称判。
