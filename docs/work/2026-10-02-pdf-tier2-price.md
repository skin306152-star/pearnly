# 按量计费：每月超出 200 页后改为 ฿1.00/页（2026-10-02）

用户定（经压测窗口转达）：只改按量计费超出部分的单价，每个自然月超出 200 页后 ฿0.75/页 → ฿1.00/页。
**上线当天起生效，已扣的费不追溯**（台账里每笔已记实收金额，改常量不会重算历史）。

不变：前 200 页 ฿1.50/页；文本文件每 50 字符 ฿0.01；S / M / L 订阅套餐；银行对账单计费页数口径
（max(物理页数, ⌈行数/40⌉)）；失败不收钱；计费月按曼谷时区。
