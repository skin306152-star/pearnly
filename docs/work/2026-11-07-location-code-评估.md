# 需求影响评估：ERP 仓位加「仓位编码」（11-07，小件窗口，待主会话审定）

## 0. 需求与范围
- 用户（经主会话 11-07）：仓库下的仓位清单加「仓位编码」；同一仓库内不重复；选仓位处按编码或名称搜、显示「编码 · 名称」；旧仓位可无编码；Express 不涉及。
- 不在范围：仓位改成独立 DocType / Link（单据、流水、结存里存的一直是**仓位名称字符串**，这次不改存法）；Cowork（没有 ERP 仓位清单，Cowork 盘点不用 `ERP Warehouse Location`）；Express / CC 桌面版（Express 没有仓位）。

## 1–3. 复用、原生、按类
- 照仓库编号的现成写法（`warehouses.code_of / label`，「编号 · 名称」，10-29 批复 #3）做仓位，不另起一套。
- 原生：子表 `ERP Warehouse Location` 加 Data 字段 `location_code`（长度 30，可空），DocType JSON 随源码，`bench migrate` 同步表结构，**不需要数据补丁**（旧行为空）。
- 「同仓不重复」放服务端：`locations.api_save_locations` 与 `ERP Warehouse` 控制器 validate 都核（任何保存路径都拦）；不加数据库唯一索引（空编码多行要允许）。
- 按类：所有选仓位的地方共用一个下拉 `p.location_query` → `locations.api_location_options`，改这一处就覆盖采购 / 销售行、出入库 / 调拨 / 物料调整行、期初、盘点录入（网页与 LINE LIFF 同一页）。

## 4. 显示与搜索（值不变）
- 下拉：按编码**或**名称搜（服务端 `or_filters`，仍按页 50 个）；选项显示「编码 · 名称」，没编码只显示名称；**值仍是仓位名称**，存进单据的不变。
- 现在选项是「名称 · 说明」（10-29 批复 #4）：改成「编码 · 名称」后说明放第三段还是不显示，要定（见 12）。
- 只读显示（单据详情、库存页、库存卡、收发存、盘点报告）照旧显示名称；要不要也改成「编码 · 名称」要定（见 12）。
- 物料「默认仓位」现在是自由填写的 Data（不绑仓库），没法按某个仓的清单下拉；建议这次不动，或改成下拉列出「本公司所有仓的仓位」（见 12）。

## 5. 隔离与权限
- 维护仍要 `warehouses.manage`、仓按所属公司核；下拉仍按 READ_CAPABILITIES 与仓的公司核。编码只在本仓内唯一，不跨公司串。

## 6. 入口
- 网页 / 手机：同一下拉。LINE：识别后问仓位那一步的按钮（`line_items._chose_location`）文字改「编码 · 名称」，按钮标签 ≤20 字，超长截断；值仍是名称。CC 对话：不涉及。

## 7. 共用件
- 改到 `transactions.js`（`p.location_query` 本身不改，只是服务端选项变）、`inventory/locations.py`、`warehouses.js`：施工时跑 `check-impact`，预计命中「单据行」「盘点」相关入口，照闸门逐个实测。

## 8–9. 成本、删除
- 无新增外部调用与存储。仓位删除 / 停用规则不变（编码随行删）。

## 10. 导入导出、打印、文案
- 导出：库存 / 收发存 / 盘点导出的仓位列现在是名称；建议加一列「仓位编码」还是不动，要定（见 12）。
- 导入：期初导入、盘点 Excel 的「仓位」列：建议**编码或名称都认**（先按本仓清单的编码找，再按名称），存名称。
- 打印：7 个打印格式都不含仓位，不涉及。
- 新增文案（官方简短）：仓位清单表格一列「仓位编码」（新词条 `stock.location.code`，四语）；重复时报错「仓位编码重复」（`Duplicate location code`）。不改已有文案。

## 11. 测试
- 单测：同仓重复编码被拒、跨仓同编码可以、空编码多行可以；下拉按编码 / 名称都搜得到、显示「编码 · 名称」、值是名称；导入按编码认。
- 流程：扩 `erp.warehouse.codes`（给仓位写编码保存、下拉显示与按编码搜）、`erp.stocktake.places`（盘点里按编码选仓位落库是名称）。
- 产品地图：仓库页仓位清单那一行（`erp.desk.pearnly-warehouses`）与下拉相关行补引用；不新增入口。

## 12. 要定的
| # | 问题 | 建议 |
|---|---|---|
| 1 | 下拉显示：「编码 · 名称」后说明还显示吗 | 「编码 · 名称 · 说明」（有说明才带），不丢 10-29 加的说明 |
| 2 | 只读显示（单据、库存页、报表）也带编码吗 | 这次不带，只改选的地方（改动面小；要带再单独评估） |
| 3 | 物料「默认仓位」要不要变下拉 | 这次不动（它不绑仓库） |
| 4 | 导出加「仓位编码」列吗 | 库存导出、盘点导出加一列；收发存不加 |

## 13. 步骤与机器耗时
- 字段 + 服务端唯一 + 下拉搜索显示 + 仓位清单列 + 导入认编码 + 单测：写代码约 1 小时；
- 流程扩写与实验栈跑（`--changed`）约 30–40 分钟；全闸门约 10 分钟。
