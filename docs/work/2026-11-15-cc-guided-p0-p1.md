## 分支 4 `pearnly/cc-guided-collection`（P1 收款，服务端一半）

基线：`pearnly/cc-guided-core`（909971dbb）+ 摘入 `pearnly/collection-date` 465b5fc7a（收款日期，未合 main；它进 main 后变基会自动去掉）。前端接线等分支 3。

| 提交 | 内容 |
|---|---|
| 引擎（共用层 `assistant/guide/`） | 步骤可带 `check`（服务端再核）、`apply`（答案收下后的一步，例：选了账套记进本对话）、`facts`（题目下的事实行）；选项可带 `facts` / `wait`（在读，页面过一会儿再取）；金额多选 / 分摊每行不超选项的 `max`；草稿 / 放行可退回某几步（`returned`，其余答案保留）；复核后草稿在别处改过回复核带新版本；开始时没定、引导里定下的账套补进记录不算失效；`when.starts` 按码前缀判；修一处缺陷：前一步默认值给不出时后一步算默认值出错（先红后绿的测试） |
| 收款引导 `collection/guide.py` + 声明改 `form` | 公司 → 收款日期 → 账套 → 客户 → 未收发票（逐张收多少）→ 现金 / 转账 / 折扣分摊 → 每种转账一张凭证 → 复核 → 确定 → 结果。全部转调 `collection.service`；客户编码、发票号按原样比；金额只来自卡上；读回在读 / 电脑没连 / 要更新照列上次读到的并加事实行，刚读回且一张没有才说「没有未收清的发票」；确定 = `service.release(…, "guide:<运行>:<版本>")` |
| 词条 | 步骤标题 `guide.step.collection.*`、复核卡 `guide.review.salesman / department`，四语沿用已有译法（新增「Transfer Slip / 转账凭证 / สลิปการโอน / 振込明細」） |
| 叫人判据 `assistant/attention.py` | 设计 15.2 服务端一半：设备报「在看哪段 + 可见」、75 秒过期、任一设备在看就不叫、`call` 唯一入口、推送发前再判。上报接口与页面一半随分支 5 |
| P2 盘点 | `docs/work/2026-11-15-cc-guided-p2-choice-points.md` |
