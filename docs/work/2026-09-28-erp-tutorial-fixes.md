## 改了什么

| # | 问题 | 改法 |
|---|---|---|
| 21 | 连续盘点把上一件的实际位置带给下一件，盖掉账面位置，结束盘点时真的调库存 | 只有账上**没有位置**的新品才沿用上一件的位置；有账面位置就用账面位置；修改已录记录不沿用。ERP 与 Cowork 两份 `stocktake-entry.js` 同改。 |
| 1 | 库存页搜索写「按名称或条码搜」，只比商品名 | `inventory/contracts.product_matches`：名称、编码、条码、二维码内容任一包含即命中（与商品列表同口径）；另按售卖单位条码精确命中。库存页「条码 / 二维码」列没有条码时显示二维码内容。 |
| 26 | LINE 按钮截到 20 字，相近名称分不清 | 选公司 / 供应商 / 客户 / 仓库时提问里列带编号的全名；按钮去掉「บริษัท / จำกัด / (มหาชน) / Co., Ltd.」等通用词。 |
| 8 | 没配 LINE 渠道的租户，个人资料页每次弹错误框 | 绑定状态带 `channel`（`pearnly_core.line.is_configured()`，共用层未改）；没配就在 LINE 块里显示已有的那句「这个账号还没配置 LINE 通道」，不发码。ERP 与 Cowork 同改。 |
| 11 | 公司税号不查校验位，采购识别却查 | `masters/contracts.tax_id_problem` 用共用层 `tax_documents` 同一校验位算法：13 位数字一律验校验位，本公司必须 13 位，外国主体非 13 位放行；公司 / 供应商 / 客户手工保存时查，只在税号变动时查；报错与识别同一句。识别自动建供应商不拦。 |
| 15 | 「单号前缀」改了不生效 | 用户定隐藏：DocType 字段 `hidden`，接口不再读写，库里旧值保留。 |
| 20 | POS 付款键盘按「分」输入 | 按标准不改：`official-pos_payment.js` 与锁定 ERPNext 16.34.1 官方原件逐行一致（官方即按分输入，v16 无快捷面额）。 |
| 16 | 入库 / 出库列表「仓库」栏为空 | 列表接口补 `warehouse_name`。 |
| 17 | 收发存明细页顶部显示仓库编号 | 库存卡接口带 `warehouse_name`，页面显示名字。 |
| 23 | 只有二维码的商品，盘点表条码列为空 | 建盘点快照时带上二维码内容；以前建的盘点读取时从商品补。 |
| 24 | 盘点 AD 单备注是 `stocktake:STC-xxxxx` | 新单写「ตรวจนับสต็อก: 盘点名称」；以前的单在列表 / 单据查看时按新口径显示（库里不改）；单据仍由 ref_type / ref_id 指回盘点。 |
| 25 | LINE 选公司提问带「ครับ」 | 泰文改为「เลือกบริษัท」。 |
| 9 | 团队列表管理员行显示英文角色名 | 与编辑弹窗同口径：管理员行列出全部功能名；只显示团队管理里能勾的功能名。 |
| 5 | 默认收银台叫「Counter 1」 | 按界面语言：泰语「จุดขาย 1」（词条 `company.terminalDefaultName`）。 |
| 4 | 建公司后左上角公司名要刷新才出现 | 建公司 / 保存公司资料后重取公司上下文，左上角公司名、页面标题、面包屑当场更新。**另修**：公司信息页「设为当前公司」按钮调用了未定义的 `set_current`，点了报脚本错误。 |
| 19 | 交班对账表列出已停用的「刷卡」 | 开班只为公司启用的付款方式建对账行（现金始终有）；老班次显示时只列启用的或这一班实际收过的；班次列表汇总同一份清单。 |
| 6 | 重复条码：扫码枪要到保存才提醒 | 单件新建弹窗的「条码 / 二维码」格回车或离开时查重；批量新建表格同样。 |

| 18 | 慢网络下扫码后立刻回车，商品没带出 | 入 / 出库明细的商品格：回车时下拉没有选中项就按码直接查商品（编码 / 条码 / 二维码 / 单位条码）并填上。 |
| 13 | 销售识别后新客户不进客户列表 | 与采购自动建供应商一致：销售单提交时对方没匹配到客户、且不是散客 / 「未知买方」，就按单据上的买方名称、类型、地址建客户档并挂上。 |
| 14 | 入库 / 出库没有「用途」 | 新增可选原生下拉：入库「退库 / 其他」，出库「内部领用 / 报损 / 其他」，服务端按方向校验；列表备注栏前带上用途。**报表按用途统计未做**。 |
| 10 | 用户名登录失败 | 原因：开关 `allow_login_using_user_name` 只由补丁打开，而新装站点不真正运行补丁，本地登录站点一直是 0。改为安装与每次迁移后幂等确保（只管本地登录站点，接统一身份的站点不动）。线上租户走统一身份，不受影响。 |
| 3 | 从个人资料页点菜单偶尔不跳转 | 测试环境共点 5 次（含一进页面立刻点）都正常，判断是录制时自动点击的时机问题，不改。 |
| 12 | 识别漏声调符号 | 识别正常误差，不改。 |
