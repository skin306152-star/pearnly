# 评估：CC 写进货单的总账照 Express 原生直接记物料科目（11-07）

> 主会话派单（混行证据窗口发现，[混行证据](2026-11-07-cc-mixed-lines-native-evidence.md) 第 2 条）。只评估，审定后再改。
> 证据脚本与输出：共享笔记 `进货总账原生-11-07/`（`pgl.py`、`pgl_out.txt`），测试机本机 95 本账套副本只读（同混行取证的抽样）。

## 1. 原生怎么记（人录的赊购 RR / 现购 HP，带库存行）

| 账套 | 张数 | 库存行借哪个科目 | 说明 |
| --- | --- | --- | --- |
| 永续盘存 `ISINFO.ISPERPETUA = Y`（65 本） | RR 27,598（57 本）、HP 409（16 本） | **物料科目组的存货科目 `ISACC.ACCNUM01`** | 另有 RR 1,254 张同时借了科目组的 ACCNUM02（单上还有别的行或改过单），26 张借账套默认存货 ACCNUM04 |
| 定期盘存 `ISPERPETUA = N`（30 本） | RR 29,395（24 本） | **物料科目组的购货科目 `ISACC.ACCNUM02`** | 借账套默认购货 `ISINFO.ACCNUM18` 的 4,470 张（10 本，多是科目组没配 ACCNUM02 的品）；借 ACCNUM01 的 1,051 张 |

- **没有重分类分录**：95 本里人录的单 SEQIT 7 / 8 成对出现的一张都没有（混行取证另见只在 18 张里出现）。
- 同一科目的几行库存品合成一条借方（51,557 张合并、17,449 张一行一条——后者多是只有一行的单）；库存行借方 SEQIT 多为 `0`（27,872），少数 `1`（2,922）。
- 进项税 SEQIT 3、应付（赊购）/ 现金（现购）SEQIT 6，与 CC 现在一样。非库存行借自己科目组的 ACCNUM01，与 CC 现在一样。
- 28,158 张单留着带删除标记的「工作行」（Express 录单过程中的中间行），不照抄。

## 2. CC 现在怎么记（`purchase_lines.journal_rows` / `_reclass_rows`、`dbf_writer._write_all`）

- 永续账套：采购行借载荷给的购货科目（SEQIT 0，金额 = 全单税前额）→ 库存行再追加一对「借 存货（科目组 ACCNUM01）/ 贷 购货」（SEQIT 7 / 8）。
  **余额与原生相同**（购货一借一贷相抵），但购货科目的明细账、发生额每张单多一借一贷。
- 定期账套：借账套默认购货 `ACCNUM18`（换掉载荷里的默认存货科目），不重分类。**余额与原生不同**：原生按物料科目组记到各自的购货科目
  （例 66BAKEL 的 5130-01 / 5130-04 / 5130-06），CC 全部记进一个 ACCNUM18，损益表上按科目分的购货金额不对。
- 混行单（载荷 19）：非库存行借自己的科目，库存行那一段同上。

## 3. 改法建议

- 只改 CC 写进货的分录（载荷不变，服务端不动）：库存行按物料科目组定借方科目——永续借 `ACCNUM01`、定期借 `ACCNUM02`（科目组没配 / 不能记账时
  退回账套默认：永续 `ACCNUM04`、定期 `ACCNUM18`，与原生那几千张一致），**同一科目合成一条、SEQIT 0**；去掉 SEQIT 7 / 8 重分类。
  非库存行、进项税、应付 / 现金不变。全库存单和混行单一起改（同一段代码）。
- 金额：库存行按行税前额（与写进 STCRD 的 NETVAL 同一个数），合计与载荷的采购借方差的零头留在原来那条采购分录上（零头为 0 就不写这条）。
- 读回 / 自检：借贷平衡自检、`write_verify` 的分录科目核对都按 CC 自己换算后的分录核，跟着改；Cowork 服务端对存货单本来就只比表头（`pushed.py`），不受影响。
- 作废：原生作废把这张凭证的分录金额清空，与分录长什么样无关；CC 自己作废只管库存单（OU / JU / TK / RL），不涉及进货单。不用改。

## 4. 影响与在 Express 报表上的差别

- 永续账套：试算表 / 资产负债表 / 损益表数字不变；购货科目的明细账不再出现 CC 单的一借一贷；凭证上少两行。
- 定期账套：**损益表按科目分的购货金额会变对**（从 ACCNUM18 挪到各科目组的购货科目）；合计不变。已经写进去的旧单不动（另议）。
- 共用件「CC 写 Express」，影响清单同结存修复那次（9 个入口）；Cowork 推送、ERP 采购（网页 / 识别 / LINE）、混行单都走这里。

## 5. 测试

- 单元：永续账套一张全库存 RR、一张混行 RR、一张 HP——分录只有「借 科目组存货（合并）+ 借 进项税 + 贷 应付 / 现金（+ 非库存行自己的科目）」，没有 SEQIT 7 / 8；
  定期账套同样三张——借科目组购货；科目组没配 ACCNUM02 的品退回 ACCNUM18；两个科目组的品各自一条。还原修复必失败。
- 离线回归：`express-stock-balance-regression.py` 加一个 `--allow GLJNLIT.*` 口径的对比——新旧只许分录行不同，且新写法按账套分类核「借方科目 = 科目组科目」。
- TEST：直写一张全库存 RR、一张混行 RR，Express 里打开凭证、看明细账，再原生作废。
