# 测试机清单：CC 桌面版 1.12.21（三批合并）实写、62 套回放、B2 探表单

属于 CC 桌面版 1.12.21 的三批改动，三批同一个版本、同一个安装包：
- 占用探测（`pearnly/express-busy-probe-2`，记录 [Express 开着不动账套](2026-11-12-express-open-no-touch.md)）；
- 载荷 21 与写入缺陷、销售员、负库存要批准、缺发票号（[载荷 21 记录](2026-11-12-cc-desktop-payload-21.md)）；
- 科目余额标待重算 GLBAL（同上记录「科目余额标待重算」一节）。

本任务窗口没连测试机；各部分互相独立，由主会话排时间。动测试机前照例先登记占用表并通知在用的窗口；服务器版 Express 开着时不写它的账套。

## 第三部分：B2 代录销售单的「อ้างอิง」（探明后才改配方）

配方 `companion/src/companion/express_operator/recipes/express-1.0.1.94.json`：IV 表头的标签列表里有「อ้างอิง」，HS 的要到机器上看。

4. 结论回给本任务窗口或主会话：格子名、长度、落哪一栏；据此在配方 IV / HS 的 `header.values` 加一格填现有的 `ref_no`，并补离线回放用例。
