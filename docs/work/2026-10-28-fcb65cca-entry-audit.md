没测到（原因）：

- **Express / CC 桌面版回写**（出入库 OU/JU/TK、日汇总 HS、退货 SR、负库存、STLOC、Express 存量同步与公司页差异表、接了 Express 的公司锁字段、拒手工期初 3f492849）：要真 Express 账套和 CC 桌面版，本地实验栈没有。
- **用登录名登录**：站点关了账号密码登录（`disable_user_pass_login=1`），正式登录走 Keycloak，实验栈没有 Keycloak。
- **LINE 里打开的手机盘点与 LINE 菜单**：只测了 LINE 外回落到本账号绑定这条路，没有真 LINE 消息。
- **本轮没覆盖**：采购混合税率与现金含税；收银小票逐行税拆分（实验公司收银走不含税口径）；入出库附件与作废（作废单打印水印）；内部编码进导入导出工作簿；导出大文件的后台推送（实验栈没起实时推送服务，socket.io 连接报错是环境原因）。
- **由验收窗口测过的**（不在本审计重复）：外壳路由与页头白名单（17 个岗位 0 漏出）、删除「采购设置」「集成」两页、去掉采购订单。

实验栈环境噪声（不是产品问题，已在驱动里分开）：网页进程在 amd64 模拟下吃内存，会被上限杀掉。批量跑时每个用例前都重起一次（`batch.sh`）；驱动在 `/desk` 页一分钟没起来时报「page not ready（web process not responding）」，不再当成页面断言失败。

## 用例与工具（`scripts/regression/flows/`，交验收接 CI）

- `lab.py`：建站、岗位、本地计费；`seed.py`：两套数据；`sid.py`：发会话；`code_video.py`：二维码 / EAN 假摄像头视频。
- `steps.mjs`：无头 Chrome 步骤驱动，带静音、假摄像头、手机宽度，结束时杀掉进程组。
- `run.py`：跑用例，做占位替换和变体，汇总通过 / 不通过；`cases/*.json` + `cases/js/*.js`：上表每一行一个用例。
- 跑法：

  ```bash
  python3 scripts/regression/flows/run.py --seed seed-new.json --seed seed-old.json scripts/regression/flows/cases/<用例>.json
  ```

  需要环境变量 `FLOWS_VIDEOS`（假摄像头视频目录）和 `FLOWS_OUT`（截图与结果目录）。问题 1、2 修好后，`mobile_count@new`、`vehicle_in_scan`、`vehicle_out_scan@new` 应转为通过。
