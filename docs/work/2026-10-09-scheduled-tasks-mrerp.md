# 定时任务（原「自动录入规则」）加 MR.ERP（2026-10-09）

分支 `pearnly/folder-rules-mrerp`，基线 `9287dd1f`（= origin/main）。用户 2026-10-09：「现在这个自动录入规则只做了本地的 exp 吗？
那 mr.erp 怎么办，重新设计前端交互，把 mr.erp 加进去，请注意做好两者的细节和视觉对齐以及交互逻辑」；只用 MR.ERP 的公司 →
「可以给 mr.erp 做一个轻量的吗」→ 选定「小助手通用、MR.ERP 成员只读文件夹」；「自动录入改为定时任务」→ 改名（文案已批）。

## 设计

- **读文件夹的永远是这条连接自己的小助手**：Express 照旧；MR.ERP 连接也能发配对码，配出来的小助手成员只读文件夹
  （不找 Express、不上报账套、不领推送任务）。同一台电脑可以同时有 Express 成员和 MR.ERP 成员，授权文件夹不许重叠照旧。
- **安全**：配对码格式不变（`exp_…@站点`）；`credentials.HELPER_ADAPTERS = ('express', 'mrerp')`，
  `FOLDER_ONLY_ADAPTERS = ('mrerp',)` 的配对码在 `http_auth` 鉴权后、绑定身份前，非文件夹机器方法一律 403。
- **配对**：小助手先用文件夹同步接口问一次连接类型（`{"probe": true}`，服务端不记本机情况、不取任务），MR.ERP → 存
  `kind=folder` 成员；其余照 Express 配对。没有 Express 的电脑也能「添加成员」。
- **推送**：MR.ERP 走与网页「提交」同一入口（`destinations.MrerpTarget`，确认一步什么都不做，服务器直接推）。

## 网页（与「新建录入」对齐）

| 项 | Express | MR.ERP |
|---|---|---|
| 最上面 | 目标 ERP 卡片（同一组件、状态、「连接」按钮，独占一行；编辑时固定） | 同左 |
| 账套 | 年度 → 账套 | 公司 → 年度 |
| 预选 | 任务原账套 → 这台浏览器上次在该连接选的（与新建录入同一个本机键）→ 连接默认 | 同左 |
| 入账方式 | 过账类型（存货 + 多个科目组时当场选一次） | 付款方式（进项只有赊账） |
| 文件夹 | 这条连接小助手的授权文件夹 | 同左；没配小助手时「连接小助手」（与「连接 Express」同一弹窗：下载、配对码、复制、重新生成） |
| 默认处理 | 有 | 无；保存前按「新建录入」同一弹窗问一次 MR.ERP 菜单与默认值 |
| 列表 | 新列「目标 ERP」，其余不变 | 同左 |
