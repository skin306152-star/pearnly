## 改动（`reconciliation/bank_sheets.py` 为主）

| 导出族 | 原来 | 现在 |
|---|---|---|
| KTB 网银 .xls | 日期是 Excel 序号读不出；Amount / Tax / Balance 三栏 | 序号换日期；代扣税另记一笔；支票类按支票日期插在别处的行，按余额链重排（只在重排后每一行都接上时采用） |
| BBL 网银新版 | 金额带「THB」后缀、扣款印负号、新的在前 | 去后缀取绝对值；整张表扣款全是负数且余额链按绝对值才接得上时按扣款；新→旧翻正；同一秒入账的「利息 + 扣税」按印出的时刻翻正 |
| KBank .xls | 「จำนวนเงินหักบัญชี」只命中「金额」，扣款全丢；表尾存取合计当成流水 | 补认扣款 / 存入栏名；只认出一侧时金额栏就是另一侧；表尾合计不再当流水、不当期初 |
| Krungsri 网银 .xls（实为 xlsx）/ 查询 CSV | 余额栏「ยอดเงินในบัญชี」不认；日期与时间之间换行；CSV 没表头；整数额转出记在前一栏 | 补认余额栏；换行日期可读；无表头 CSV 按列位置认（带日期 ≥3 行、九成五以上余额链一致才用）；前一栏的金额接上；「ถอนเงินรวม / ฝากเงินรวม」表尾截止 |
| SCB / Krungsri XLSX | 表格范围写错只读出一行 | 读前重算范围 |
| ICBC | 「合计金额」写在序号栏被当流水、下面客户加的核对数被当期初；UTF-16 CSV 读不出；印「没有满足条件的记录」 | 别的栏写着合计即表尾截止；UTF-16 解码；按「没有流水」 |
| 多账户 / 多月份 | 读完合起来再按合计期初跑一遍余额链，每个账户第一行判断链；按月分 sheet 的同一账户期初期末被加总 | 多账户各按自己的期初定案，不再合跑；前一个 sheet 期末 = 后一个期初、日期接得上、账号不冲突的合成一个账户 |
| 客户自制表 | 「Withdraw」栏写说明、金额在「Amount」栏；手打「6/1/69」被 Excel 存成 1969-06-01；月底存取小计；同表下面接另一年的数据 | 文字栏改认摘要、金额栏接手；佛历短年份换回并按前后日期决定日 / 月是否对调；月小计跳过；表内再出现表头另起一段 |
| 总账 | 放进账单口时报「读不出」 | 认出是总账，说清楚放错口（`reconciliation.statement_is_ledger` / `files_ledger_not_statement` 四语） |

`bank_intake.py`：表格直读的期初期末由读取器定，0 也是真值（KTB 归集户期末真是 0，原来被换成最后一个非 0 余额）；多账户不再合跑定案。
