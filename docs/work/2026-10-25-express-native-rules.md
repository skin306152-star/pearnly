# Express 原生规则参考（实录）

来源：验收窗口 10-25 在服务器测试账套 `\\accserver\d$\account\70EXP\test`（公司「9.ข้อมูลทดสอบ」，代码 DATAT）用 Express 1.0.1.94 亲手录单。
方法：每一步录前 / 录后把整本账套只读拷到测试机，按 DBF 原始字节逐表比对。
原始记录与截图清单见同目录「服务器test账套-录单结果.md」，各步副本在测试机 `C:\PearnlyStress\_srvtest_record\`。
用途：写标准流程、CC 直接写 Express 时以此为准。只写实测到的；没测的单独标「未测」。

> 交给开发：收进 `pearnly/erp-stock-research` 的 docs（建议 `docs/work/` 或该分支的研究目录），之后改动以实测为准更新。

## 1. 菜单路径（这本账套的菜单，以 Alt+数字键 进入）

| 功能 | 路径 | 单据前缀 |
|---|---|---|
| 赊购 / 收货 | 1.ซื้อ → 4 ซื้อเงินเชื่อ | RR |
| 现购 | 1.ซื้อ → 2 → 1 ซื้อเงินสด-ทั่วไป（另有 2 ซื้อโดยโอนผ่าน TMB…，为专门的转账现购类型） | HP |
| 赊销 | 2.ขาย → 4 ขายเงินเชื่อ | IV |
| 现销 | 2.ขาย → 2 → 1 ขายเงินสด-หน้าลาน | HS |
| 退货 / 减价 | 3.การเงิน → 1.รับเงิน → 4 ใบลดหนี้/รับคืนสินค้า（不在「ขาย」菜单下） | SR |
| 领用 | 4.สินค้า → 1 → 1 → 1 จ่ายสินค้าใช้ภายใน | OU |
| 仓间调拨 | 4.สินค้า → 1 → 2 โอนย้ายระหว่างคลัง | RL |
| 商品资料 | 4.สินค้า → 2 รายละเอียดสินค้า | — |
| 计算成本 | 4.สินค้า → 7 ซ่อมแซมระบบสินค้า → 4 คำนวณยอดสะสม/คงเหลือ/ลงบัญชี | — |
| 库存设置 | 7.เริ่มระบบ → 1 กำหนดค่าเริ่มต้นต่างๆ → 3 ระบบสินค้าคงเหลือ → 1 | — |

单据工具栏：新建、编辑、作废（第 3 个，红章）、删除、取消、保存……；保存时 Express 才给单号（新单显示「前缀NEW」）。

## 2. 负库存设置

### 2.1 账套级（ISINFO）
库存设置画面第 9 项「ยอดคงเหลือสินค้าติดลบได้ [Y/N/A]」= **NEGALLOW**；第 11 项「ระดับการตรวจสอบยอดสินค้าติดลบ [0-2]」= **CHKNEGLEV**。
保存后确认框 Message#.1311 点 ตกลง 即生效，**不用退出重进**。

### 2.2 商品级（STMAS.NEGALLOW）
商品资料画面「ส/คติดลบได้? [Y, N, A]」。空 = 跟随账套。测试账套 282 个商品里 14 个是 Y，其余为空。A 的含义未测。

### 2.3 实测判定（都是「从 01 仓卖」，Express 录行时以行上的仓为准）

| 账套 NEGALLOW / CHKNEGLEV | 商品 NEGALLOW | 情形 | Express 反应 |
|---|---|---|---|
| N / 2 | 空 | 01 仓 0、02 仓 10，卖 3 | 录行即弹 **4224**「ยอดคงเหลือของสินค้าติดลบ รหัสสินค้าทดแทน=[ ]」，行进不去；**按单仓查，不看全仓合计** |
| N / 1 | 空 | 同上 | 与 2 相同，4224 硬拦 |
| N / 0 | 空 | 卖 3（全仓够） | **不提示，存成功，01 仓变 −3** |
| N / 0 | 空 | 卖 20（超过全仓合计） | 录行不提示；**保存时**弹 **4091**「ยอดสินค้าติดลบ รหัสสินค้า [x] คลัง [01]」拒存 |
| N / 2 | **Y** | 01 仓 3，卖 5 | 只弹 **605**「ยอดสินค้าคงเหลือติดลบ」提醒，照存，01 仓变 −2 → **商品 Y 盖过账套硬拦** |
| Y / 0 | **N** | 01 仓 9，卖 15 | 行完成时弹 **4091** 拒收该行 → **商品 N 盖过账套放行** |
| Y / 0 | 空 | 01 仓 0，卖 2 | 不提示，照存 |
| Y / 0 | **N** | 01 仓 −2、全仓 7，卖 1 | 不提示，照存（IV0000036）→ 商品 N + 0 级按**全仓** |
| Y / 2 | **N** | 01 仓 −3、全仓 6，卖 1 | 录行弹 **4224** 拦（空单头 IV0000037）→ 商品 N + 1/2 级按**单仓** |
| Y / 2 | 空 | 01 仓 9，卖 15 | 不提示，照存（IV0000038）→ 账套允许时 CHKNEGLEV 对没标 N 的品不起作用 |

**归纳**：「这件品要查」= 商品 N，或（商品空 / A 且账套 NEGALLOW=N）。要查的品按账套 CHKNEGLEV 判：0 = 全仓合计（保存时 4091），1 / 2 = 单仓（录行 4224），空按 2。商品 Y 只弹 605 提醒。

- 全程没有密码 / 审批（NEGAUTH 为空）。
- **被拦后**：中途写的 STCRD / GLJNL / GLJNLIT 行打删除标记回滚，但 **ARTRN 仍留一张金额 0 的空单头，并占用一个单号**（ISRUN +1）。
- 录行时的仓库下拉只列「该商品有 STLOC 行」的仓；手输别的仓不被接受。

## 4. 各单据的落库写法

### 4.1 赊购 RR（收货）
APTRN 1 行；STCRD 1 行（MLOTNUM「B/F」，LOTBAL / LOTVAL 记批次）；STLOC 该仓 +（没有该仓行时**新增 STLOC 行**）；STMAS 结存与金额；GL（JNLTYP 进货）；ISVAT（P）；APMAS / APBAL。
**存进货单时会回填之前负库存销售行的成本**：该销售行 STCRD 的 XUNITPR / XTRNVAL 改为进货价、MLOTNUM 指向这张进货；该销售的成本凭证（借 51-01 / 贷 11-04-04）同时补写。

### 4.2 赊销 IV
ARTRN（RECTYP 3）；STCRD（POSOPR 9，PEOPLE=客户，XUNITPR 按批次取，MLOTNUM 指向来源批次）；
- 这本 LOC_COST=N（不分仓计成本）：从 01 仓卖，成本照样取 02 仓那批的 45（1-乙）。
- 超卖时成本只按现有批次摊：01 仓 3 个（180）卖 5 个，XUNITPR=36、XTRNVAL=180，结存 −2、金额 0（1-戊①）。
其余：STLOC / STMAS 减；GL 5 行（应收、销售、销项税、成本 / 存货）；ISVAT（S）；ARMAS.BALANCE、ARBAL；ARMAS.LASIVC。

### 4.3 现购 HP 与付款方式
保存时**不弹付款框**，默认全额现金（APTRN.CSHPAY，贷 11-01-01-00）。
改转账：编辑 → 付款页「รายการจ่ายชำระ」→ 双击「ชำระโดยอื่นๆ」格选付款类型（这本有 QP / TS / TN / CN / KT / TA / MD…）。选 TA 后：
- **参考号自动填「付款类型码 + 单号」**（TAHP0000006），金额自动为应付余额，日期空；
- 落库：**APRCPCQ** 新增（RCPNUM、CHQNUM、PAYAMT）；APTRN 的 CSHPAY→0、CHQPAY / CHQPAS = 金额；现金凭证行删除标记、改贷付款类型科目（TA = 11-01-03-03）；
- **BKTRN 不写**。
- 现象：APTRN.ADVNUM 曾被写成「AE」（扣订金栏自己出现，金额 0），视为 Express 现象。

### 4.3b 现销 HS 收款类型（10-25 实录）
- 默认全额现金：ARTRN RECTYP 1、CSHRCV = 金额、CHQRCV 0、CMPLAPP Y，凭证借现金 11-01-01-00。
- 收款类型在 ISRUN DOCTYP=ZR（QR 支票、CH 现金、TR 转账（这本没配科目）、TF、VS 刷卡、DC、TX、EX…）。
- **HS 上选非现金类型（VS / QR）后，Express 弹的是「选已登记支票 / 收款」清单，不会像付款端那样自动生成参考号**；要先在 3.การเงิน 登记收票 / 刷卡，再在 HS 里挂。ARRCPCQ 写法待实录。
- 进编辑再取消，ARTRN.ADVNUM 也会被写成「AI」（现购 HP 是「AE」），金额 0，视为 Express 现象。

### 4.4 退货 SR（当场退现金）
填原单号 → 原税票金额框 → 退货明细框（รับคืนสินค้า Y=回仓 / N=只减价、回哪个仓、数量、金额要手改）→ 勾选原单行 → ทำงาน <F5> → **二选一「จ่ายคืนเป็นเงินสด」/「เก็บไว้หักตอนรับชำระหนี้」**。
退现金：直接存好，不用另录付款单。
- ARTRN RECTYP 5、CNTYP 3、SONUM=原单、IVCAMT=原单金额、RCVAMT=退款额、CMPLAPP=Y；
- GL：借 41-02 退货 + 借销项税 / **贷 11-01-01-00 现金**；成本回冲借存货 / 贷 51-01；
- STCRD POSOPR 2、RDOCNUM「原单号 + 行号」、RETSTK=Y、成本按原批次；STLOC 回仓；ISVAT 新增一行 VATREC S、RECTYP 5、AMT01 / VAT01 为**正数**、REFNUM = SR 自己的单号；
- ARMAS.BALANCE、ARBAL.SR 也会减（尽管应收科目没动）。
- 「只减价」「留着抵下次收款」两种**未测**。

### 4.5 领用 OU
STTRN 1 行（POSOPR 6、ACCNUMDR 费用科目）；STCRD（成本自动带当前成本）；GL（JNLTYP 00）2 行；STLOC 减。

### 4.6 调拨 RL
STCRD **一对**：调出仓 POSOPR 4（PEOPLE=对方仓）+ 调入仓 POSOPR 3（PEOPLE=来源仓），同 DOCNUM、同 SEQNUM，MLOTNUM 指向同一批次，**不带金额**，REIMBURSE=`\x00`；STTRN 1 行（POSOPR 4、LOCCOD 调出仓、PEOPLE 调入仓）；STLOC 两仓各增减；STMAS 不变；**不写 GL**。

#### 4.6b 两行调拨与作废（10-26 补录：RL0000002、RL0000003）

逐字段比对副本 `_srvtest_record\s12-before → s12-rl2 → s12-rl3 → s12-rl3v`：

- **两行**（RL0000002，01 → 02：501780 × 1、000004 × 1；000004 在 02 仓原来没有 STLOC 行）：
  - STTRN 1 行：POSOPR 4、LOCCOD = 调出仓 01、PEOPLE = 调入仓 02、REMARK = 单头说明（录入大写，存成小写「rl test 2 lines」）、NXTSEQ = 行数，右对齐 3 位「  2」、DOCSTAT N、USERID、CHGDAT。不带金额。
  - STCRD 每件一对，共 4 行：同 DOCNUM、同 SEQNUM（右对齐 3 位「  1」「  2」）；调出行 POSOPR 4、LOCCOD 01、PEOPLE 02，调入行 POSOPR 3、LOCCOD 02、PEOPLE 01。
    两行都是 TRNQTY / XTRNQTY = 数量、TQUCOD = 商品单位、TFACTOR 1，**UNITPR / TRNVAL / XUNITPR / XTRNVAL 全空**。
    STKDES 写的是**单头说明**，不是品名。REIMBURSE = `\x00`。MLOTNUM 指来源批次（有进货批次的指那张进货行，没有的写「B/F」）。MREMBAL / MREMVAL = 写后全仓结存（调拨不改全仓结存）。
  - STLOC：调出仓 LOCBAL、QTY12NY −1，调入仓 +1。调入仓原来没有这件商品的行时**新建一行**（只有 STKCOD、LOCCOD、LOCBAL、QTY12NY、STATUS A，金额栏为空）。
  - STMAS 不变；不写 GL；ISRUN 的 RL 号 +1。
  - 同时改了旧行：这件商品早先几行 STCRD 的 MLOTNUM 被 Express 重排（例如「B/F」→「-/F」，或改指 TK0000001 那批），是 Express 自己的批次链，CC 写 RL 时不必照做。
- **作废**（RL0000003，02 → 01 一行，存完再作废）：
  - STTRN 留行，DOCSTAT N → **C**，NXTSEQ 清空；
  - 那一对 STCRD **打删除标记**（字段不改，SEQNUM 不改成「@@@」，与赊销 IV 不同）；
  - STLOC 两仓回滚；批次链 MLOTNUM 改回原样；
  - 不写 GL，ISRUN 不回退。
- 录法：Alt+4 → 1 → 2，打开时弹 **2810**、保存时弹 **43**，点 ตกลง 照常保存。调出仓默认 01（要改先 Home+Shift+End 清空），回车到调入仓，再到说明、明细。明细只有品码 → 数量 → 单位框，没有价格栏。

### 4.9 单据附加说明 ARTRNRM（10-26 补录：IV0000040、RR0000014）

- **录法**：明细行录完（光标离开那一行，或点选那一行）→ 工具栏「Note」→ 弹「ป้อนหมายเหตุเพิ่มเติม」（截图 `../reference/express-operator-playbook/line-remark-dialog.png`）。
  - 一行最多 **10 条**，每条一格，按回车跳下一格；按钮有 ตกลง / ยกเลิก / ลบบรรทัด / เพิ่มบรรทัด。
  - 光标在单头时 Note 是灰的。
  - 必须在**录单时（存档前）**录；对已存的单「编辑 → Note」改说明不落库（10-26 上午 IV0000039 那次）。
- **落库**：一条说明 = ARTRNRM 一行。
  - DOCNUM = 单号；SEQNUM C8 = 明细行号**右对齐 3 位再补空格到 8 位**（「  1     」「  2     」）；REMARK C50。
  - 同一行的多条按录入顺序排；第 1 行 3 条、第 2 行 1 条，共 4 行。
  - 正好 50 个字符的那条完整存下。
  - 只写 ARTRNRM，ARTRN / STCRD 不因说明多出任何字段。
- **赊购 RR 也写同一张 ARTRNRM**（DOCNUM = RR 单号，SEQNUM 同样右对齐）。没有单独的 APTRNRM 表。
- **RR 单头「หมายเหตุ」栏写进 APTRN.YOUREF**（C30），不进 ARTRNRM。IV 单头没有这一栏。
  - 原生样本里 SEQNUM「@n」的整单说明，这本账套没录出来入口（疑为从订单 SO / PO 的「หมายเหตุของใบสั่ง…」带过来）——**未测**。
- **打印**：Alt+P（或打印键下拉 → 1 → 表单 1）→ 选「จอภาพ」屏幕预览，只看不打纸（截图 `../reference/express-operator-playbook/iv-print-line-remarks.png`）。
  - 说明**印在所属商品行正下方**，每条一行，顺序同录入，不印行号。
  - 50 字符那条会超出「รหัสสินค้า/รายละเอียด」栏宽，压到「คลัง」栏的竖线上；这张表单这一栏约能放 40 个字符。
  - **屏幕预览不写任何表**：前后副本零差异，ARTRN 的 PRNCNT / PRNDAT 不变。
  - 预览窗口右上「×」关闭即回到单据。10-26 中午那次卡死这次没有复现。
- **作废**（IV0000040）：
  - 这张单的 4 条行说明**全部打删除标记**（字段不改）；
  - ARTRN DOCSTAT C、金额清 0、CMPLAPP Y、CMPLDAT = 作废日、NXTSEQ 清空；
  - STCRD 两行 SEQNUM 改「@@@」、TRNVAL 0 并打删除标记（同 4.7）。
- 「编辑 → 取消」（没改任何东西）：前后副本零差异。这本账套这次没出现 ADVNUM「AI」（与 10-25 HS 的现象不同）。
- 给 CC 写法的结论：
  - 车架号 / 发动机号 / 颜色各写一条 ARTRNRM，SEQNUM 照原生右对齐 3 位补到 C8。
  - 每条 ≤ 50 字节（cp874）；要让打印不压线，每条 ≤ 40 字符。
  - 作废时给这张单的说明行打删除标记。

#### 4.9 补（11-02 车架号窗口，服务器版 Express 69EXP\TEST，CC 自动登录开 Express，写后整本还原）

- **CC 写进去的行说明 Express 照样认**：CC 写的现购 HP（`HP691102-001`，一行两条「เลขตัวถัง MP1TFR41JTG032993」「เลขเครื่อง FUK575 สี ELG」）
  屏幕预览印在商品行正下方（截图 `../reference/express-operator-playbook/hp-print-unit-remarks.png`）。
- **一行多于 10 条**（`HP691102-002`，一行 12 条「S/N TEST-01…12」）：Express 正常打开；打印（输出到文本文件核对）这张表单明细区每页 8 行，
  第 1 页印商品行 + 01–07，第 2 页接着印 08–12，合计在最后一页，一条不少；「编辑 → 不改 → 保存」后 ARTRNRM 一条不动（不重写说明）。
  界面的 Note 弹窗只有 10 格（4.9 录法），多出的只是界面里改不到。
- **现购 HP 原生作废**（明细是非库存品 PN00033 的那张）：APTRN DOCSTAT C、金额清 0；GLJNL C、GLJNLIT 金额清空；ISVAT C、清 0；
  STCRD 那一行 SEQNUM 改「@@@」并打删除标记（同 4.7 赊销）；**两条行说明打删除标记、字段不改**；ISRUN 不回退。
- **CC 直接科目行的单在 Express 里作废不了**：明细 STKCOD 放科目码（`11-04-02-00`）的 HP，原生作废弹 Message#. 2101「找不到商品编码」，
