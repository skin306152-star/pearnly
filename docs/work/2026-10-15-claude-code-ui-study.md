# 研究：Claude Code 界面的交互与视觉（为 CC 前端重构，2026-10-15）

用户原话：「code 这边界面很舒服，我感觉你们还是没有抓住 code 交互的前端核心」「想下办法，把 claude 的交互摸清楚」
「还有视觉布局，我觉得抓完和试完后还是要重构下，好好研究下」。

做法：Claude 桌面版的 Code 与网页版 `claude.ai/code` 是同一套前端（桌面版多本机项目分组、子会话）。在内置浏览器里登录网页版，
**用脚本批量读页面的结构、设计变量与实际样式**，再对只有操作才看得到的交互逐项实测（悬停、点击折叠、菜单、面板、步骤展开）。
不抄对方源代码（私有、压缩过）；只记规格与数值，CC 用自己的代码实现。实测中改过的两处界面状态（侧栏分组、会话栏）已复原。

## 1. 为什么「舒服」——五条核心

1. **一种密度贯穿全局**：列表行 26–28px、行字 13/14px、组标题 12/13px、正文 14px / 行高 20px、图标 16/20px。聊天页（我们当初照抄的）
   正文 16px，换到工作台显得松、跳。
2. **一套叠色表达全部状态**：悬停 = 5% 叠色，选中 = 10%，边框 = 10%，强边框 = 20%（浅色叠黑、深色叠白）。不另造灰色。
3. **平时干净，经过才出现**：组标题的箭头、组的操作图标、行尾「···」、置顶区，只在鼠标进入侧栏或该行时淡入（0.12 秒）。
4. **点哪里都对**：组标题整行就是开关；行与按钮都有加大的命中区（上下各多 7px），不用瞄准小图标。
5. **细节默认收起成一行摘要**：连续工具步骤合成一行「已运行 2 个命令（1 个失败）›」，点开才是逐步明细；右侧栏卡片可折叠、空的直接不显示。

## 3. 版面

- 侧栏宽 288px（可拖宽），桌面版离窗口边 8px、浮起成卡片；网页版贴边。顶部标题区 44px（品牌 + 「聊天 / 代码」切换），
  搜索框 32px 高、圆角 8、5% 叠色底、内描 0.5px。
- 顶部导航：新建、项目（测试版）、Artifacts、自定义、更多。下面是会话列表（已置顶 / 最近使用 / 分组）。底部托盘 48px：头像 + 名字 · 套餐、反馈、搜索。
- 对话栏居中 768px；用户消息右侧浅底气泡；正文 14/20；表格带细线。输入框同宽 768，下面一条「下巴」46px（环境、仓库、权限、模型、用量环）。
- 标题栏：会话标题（点即改名）+「⌄」菜单；右上：会话栏、更改、文件、分享、查看选项。
- 右侧会话栏 278px：一张张卡片（环境：连接 / 项目文件夹 / 分支；上下文；更改；输出……），每张可折叠、可拖动手柄换序，没内容的不显示；窄屏时悬浮在对话上方，宽屏停靠。

## 4. 交互清单（实测 + 结构标记）

**侧栏**
- 分组依据：无 / 状态 / 日期 / 环境（桌面版另有按本机项目），排序：上次更新等；可「新建部分」自建分区；「恢复默认设置」只在改过时可点。
- 组标题：整行（除右侧 48px 操作区）是一个开关按钮，`aria-expanded`；点名字或空白都折叠 / 展开；箭头只在悬停时出现在名字后（收起 ›、展开 ⌄）；
  标题字平时最淡、鼠标进侧栏变次要色；右侧操作（分组排序、该组专属图标、＋）悬停才出现。分区可拖动排序。
- 行：单行 32px 命中、带说明的两行（标题 + 所属项目）54px；默认次要色，选中主色 + 10% 叠色底，悬停 5% 叠色底（深色实测悬停与选中同为 7.5% 的包裹底，区别在字色）；
  悬停出现行尾「···」（24px）；行尾状态图标（运行中圆点、本机 / 云端图标）；子会话缩进 20px 并画树线；`data-jump-hint-row` 对应 ⌘1–9 跳转；
  列表方向键移动焦点（roving）；可多选；长按（触屏）出菜单。
- 侧栏可整体收起成左上角的小圆按钮；鼠标靠近边缘有吸附提示；可拖宽。

**对话区**
- 连续工具步骤合成一行灰色摘要（按类计数 + 失败数）›；展开为细框列表，每步一行可再展开，失败行尾红色「失败」。
- 消息悬停出现操作；长对话虚拟化渲染；回复中输入框可排队（⌘↩ 加入队列）。

**右侧会话栏**：卡片折叠 / 拖序 / 空卡隐藏；面板开关在标题栏右上。

## 5. CC 现状差距（摘）

| 方面 | Code | CC 现在 |
|---|---|---|
| 设计变量来源 | 桌面框架 `--df-*` + `--cds-*` | 当初照聊天页 `--ccs-*`：悬停 / 选中 4% / 6%（浅），缓动 (0.2,0.8,0.2,1) |
| 密度 | 13–14px 行字、14/20 正文 | 聊天页尺寸，偏松 |
| 组标题 | 整行开关、悬停才出箭头与操作 | 只有左侧小箭头能折叠，名字是跳主档页；箭头常驻 |
| 选中 | 只落在具体的行 | 主档页时落在顶部「公司」、按公司筛选任务时落在顶部「定时任务」 |
| 公司信息 | （对应）右侧会话栏卡片随会话显示 | 单独的主档页，与对话分离 |
| 工具步骤 | 合并成一行摘要 + 细框明细 | 逐步显示进行时名称 |
| 快捷与键盘 | ⌘1–9、方向键、多选 | 基本没有 |

## 6. 重构方案（待用户定方向后施工）

**原则**：照 Code 的框架重做 CC 外壳，一次到位，不做过渡版；业务（公司、月份、待处理、定时任务、月结台账）放进这个框架，而不是另起页面。

- **设计变量**：`globals.css` 换成本文第 2 节的两套（浅 / 深）+ 两档密度（电脑默认舒适档、手机另有触屏尺寸），`docs/development/ccs.md` 与写死数值闸门同步。
- **侧栏**：照第 4 节逐项做——公司 = 分组（像 Code 的项目），月份对话 = 行（标题 + 第二行「9 月 · 分店 00012」）；组标题整行开关；悬停揭示；行尾运行圆点与「···」；
  ⌘1–9；方向键；分组依据（公司 / 月份 / 无）与排序；置顶区。「待处理」「定时任务」「公司」放顶部导航。
- **右侧栏取代主档页的日常用途**：打开某家公司的对话时，右侧栏按卡片显示这家公司：公司（税号 / 分店 / 月份）、本月（第 1 期月结台账就落在这里）、待处理、
  知识库、单据文件夹、定时任务、记住的选择、申报草稿、输出文件；可折叠、拖序、空卡隐藏。主档页保留为「公司」导航下的管理页（改名、删除、账套），样式同 Code 的项目页。
- **对话区**：工具步骤改为一行摘要 + 细框明细；正文 14/20；输入框下巴放公司 / 月份 / 模型。
- **手机**：保留已做好的返回键栈、弹窗兜底、长按规则，按 Code 的手机抽屉变体调整尺寸。

估时（机器）：写代码约 22 小时（变量与密度 3、侧栏 7、右侧栏与主档页 6、对话区 3、手机 3），机器跑约 3 小时，加两轮真机点验。
放在明天第 1 批前端线的最前面：月结台账（第 1 期）直接建在新右侧栏里；T5 多电脑（后端 / 桌面版）不受影响，照常并行。

## 7. 用户已定（2026-10-15）

用户原话：「四条都按你的建议：公司信息放右侧栏、密度照 Code、键盘这批做、组标题纯 Code 行为。明天第 1 批先做前端重构。」

1. 公司信息的日常位置：**右侧栏卡片**；主档页保留为「公司」导航下的管理页。
2. 电脑端密度：**照 Code**（行字 14、正文 14/20 等，见第 2 节）。
3. 键盘：⌘1–9 跳转、方向键、多选 **这批做**。
4. 组标题：**纯 Code 行为**（整行只折叠 / 展开，悬停揭示箭头与操作；主档页从「···」或「公司」导航进入）。
