# 没有收银台的公司点不了开班（2026-11-17）

分支 `pearnly/pos-shift-no-terminal`，基线 origin/main `803f0da84`。来源：流程工具窗口 11-16 只读推断，主会话派。

## 现象（实验栈复现）
开户自动建的默认公司（`masters/company.ensure_default`）和接 Express 的公司都不建收银台。之后开了收银，收银页点「开班」→ 开班框里
「收银台」是必填下拉、没有选项，点开班报「以下字段缺少值：收银台」，开不了班。电脑宽度、手机宽度都一样（新流程首跑：新开户两格不通过，
老数据两格通过）。连带：没有收银台时期初金额表退回列全部四种收款方式（收款方式跟着收银台回），不是这家公司配置的那几种。
服务端开班不传收银台时本来会按 `terminals.resolve` → `ensure_default` 建默认那台（挂主仓）；`erp.cashier.first-sale` 直接调开班接口，
没走这个框，所以没测到。

## 改动
- 开班框（`pearnly-pos-shift.js`，收银台页与班次页共用）：列出的收银台为空时，先调新写接口 `api_ensure_terminal`（POST，判据同开班
  `cashier.write`，按开班同一条规则 `terminals.resolve` 建出默认那台并提交），再列一次。之后开班框与有收银台时完全一样：收银台、公司、
  仓库带出，收款方式按公司配置。
- 新流程 `erp.cashier.open-shift-dialog`（新开户 / 老数据 × 电脑 / 手机）：点页面上的「开班」走开班框，断言没有「必填且没选项」的
  收银台下拉、点开班开出班，库里班次在这家公司的收银台上、新公司建出的那台挂主仓；收尾删掉本格开出的班和建出的收银台。

## 按类
扫了三个产品 Desk JS 里「必填且选项来自变量」的下拉：推送目标「库存科目组」只在候选两个以上时才问；Cowork 文件夹规则的账套 / 文件夹
下拉没有电脑时为空，但框里有读取中 / 读取失败 / 连接 CC 桌面版的状态与按钮，是设计好的引导；任务看板总有默认看板；开班框收款方式至少
有现金。同类只有收银台这一处。

## 验证
新流程修复前 2/4（新开户两格报缺收银台）、修复后 4/4、无残留数据。全闸门、候选离线、并集流程见主会话汇报。
