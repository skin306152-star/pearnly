## 0. 怎么摸的

- 内置浏览器登录 `claude.ai/code`（网页版，与桌面版 Code 同一套前端；桌面版差异按样式表里的 `data-variant="desktop"` 规则记）。视口 1440×900 与手机 375×812，浅色、深色各一遍。
- 用脚本读**设计系统本身**：Claude 的组件带 `data-cds="组件名"`，变量分三层：`--cds-*`（设计系统，约 500 个）、`--df-*`（桌面框架：侧栏、行、托盘）、组件私有变量。读的是样式表定义和计算后的实际值，再逐个组件读实际尺寸、颜色、悬停 / 选中 / 焦点状态。
- 交互逐项实测：悬停、组标题折叠、行「···」菜单、「分组和排序」菜单与子菜单、方向键、Shift 多选与批量菜单、工具步骤摘要的展开、右侧会话栏、项目页、项目列表、手机抽屉。
- 只读规格、不抄源代码。实测时打开过的会话栏已关回原状；聊天模式切回 Code 模式。

### 2.4 阴影与动效

- 卡片：浅 `0 0 0 1px 黑6%, 0 4px 24px 黑4%`；深 `inset 0 0 0 1px 白6%, 0 4px 24px 黑8%`。
- 悬浮：`0 0 0 .5px #0000000d, 0 2px 8px #0000000a, 0 12px 32px #00000008`（深色 `#ffffff0f / #0000004d / #00000040`）。
- 弹出（菜单）：`0 0 0 .5px #0000000f, 0 4px 12px #0000000f, 0 16px 40px #00000014`（深色 `#ffffff14 / #0006 / #00000080`），另加 1px 内环（线色）。
- 输入框：1px 环（线色）+ `0 4px 20px 黑3.5%`。
- 缓动：`cubic-bezier(.32,.72,0,1)`（主）、`(.2,0,0,1)`（快）、`(.165,.84,.44,1)`（淡出）；时长 60 / 120 / 200 / 300 / 450ms。悬停揭示用 120ms。

## 3. 组件规格（实测）

**3.1 侧栏外框**：宽 288，可拖宽、可收起成左上角小圆钮（收起后钮 32）。标题区 44：收起钮 24 + 品牌。网页版贴边；桌面窗口浮成卡片（离边 8px）。

**3.2 搜索框**：高 32、圆角 8；浅色 白50% 底，深色 白5% 底；0.5px 内环（线色）+ `0 1px 2px 黑5%`；占位字淡色 14px；右侧 12px 淡色快捷键提示。

**3.3 顶部导航行**：高 32、圆角 8、字 14 次要色、图标 20 放在 28 的前导槽里；当前页：选中底 + 主色字；行尾 24 的操作按钮悬停才出现（例：「项目」行尾「新建项目」）。

**3.4 组标题**：带高 32，左内边距 10。整行（除右侧操作区）是一个开关按钮：高 24、圆角 8，`aria-expanded`。名字 13/16 淡色，鼠标在组标题上变次要色，展开状态的开关字为主色口径。名字后 12px 箭头（收起 ›、展开 ⌄），鼠标进入侧栏才淡入。右侧操作 24×24：平时只露「分组和排序」，悬停组标题再出「新建」。
CC 侧栏改动（用户 2026-10-15 夜，配图与录屏来自 DeepSeek 桌面端；原话「侧栏还是这样做吧，参考图一，图标换成我们自己公司的图标，然后才是公司名字，然后展开收起，下面是对话……打开现在的打开公司和在这家新建对话，不要了，换成图三的内容……+还是保留，点+就在这个公司内新建对话，图4点图标就不要了」，随后补充「只改我提到的地方 其它不要动」）：
- 公司组头：最左公司图标（lucide `Building2Icon`，原「打开公司」菜单项那个，16、淡色），图标与名字隔开 6（开关的 4 + 行间距 2）；公司名同会话行标题的字号字色（14/20 次要色、常规字重，不用组标题 13/16 淡色）；整行仍是折叠开关，名字后箭头、待处理数、收起时的点、长按、菜单键、带高照旧；这家的对话行缩进到公司名文字起点（电脑、桌面窗口、手机抽屉同样）。已置顶 / 最近 / 月份组标题样式不变、下面的行不缩进。
- 右侧操作：「分组和排序」漏斗按钮从所有组标题上去掉；每个组标题右侧悬停才出「···」（手机、触屏常显），打开的就是原「分组和排序」菜单（3.6 的分组依据 / 排序方式 / 显示 / 恢复默认设置，子菜单、✓、当前值、禁用规则不变）。公司组「···」里原来的「打开公司」「在这家新建对话」去掉；手机长按组头、键盘菜单键打开的也是这份菜单。「＋」照旧（公司组：在这家开新对话、月份上个月；最近：开在最近）。
- 公司页入口改为：对话顶栏「公司名 ›」/ 手机胶囊菜单打开会话栏 → 公司卡名称；侧栏导航「公司」→ 公司列表页卡片。

**3.5 会话行**：高 32、行间 2、圆角 8；标题 14 次要色，超长渐隐；行尾 24 槽放装饰：运行中 6px 脉冲点（淡色、明暗呼吸 1.2s）、环境 / 设备图标 16 淡色、未读点。悬停：行底 = 悬停色，装饰淡出、换成「···」24（圆角 6）。选中：底 = 选中色、字主色。键盘焦点：蓝色焦点环、露出「···」。「显示 → 元数据」打开时为两行行（标题 + 说明行）。
悬停滚动（用户 2026-10-15 夜，同上，参考录屏逐帧量过；Claude Code 没有这一条）：凡是单行、放不下被截断的文字（侧栏对话标题与元数据行、组名，会话栏卡片里的行，公司页对话行与标题，菜单里的公司名，标题栏对话名，列表页、待处理、设置等行），鼠标放到这一行上、或键盘焦点落到这一行时，约 150ms 后从开头匀速（约 40px/s、线性，时长 = 超出像素 ÷ 40，至少 0.3s）向左滚到末尾刚好露出（原有右端渐隐也让过去）并停住；滚动中左端 24 渐隐、右端保留原有渐隐；离开 / 失焦立即回到开头，没有回滚动画。放得下的不滚；系统减少动态效果、触屏 / 不能悬停的设备、就地改名中、拖动中不滚。静止时的截断样式（渐隐 / 省略号）不变。实现：`lib/hover-scroll.ts` + `components/ui/marquee.tsx`，参数在 `globals.css` 的 `--cc-marquee-*`，悬停时才量，不常驻观察。

**3.6 菜单**：圆角 12、内边距 4、最小宽 128；底 弹层色、1px 内环 + 弹出阴影；项高 32、圆角 8、内边距 6/10、14/20；分隔线 1px、左右内缩 10、上下 4；右侧单字母快捷键（淡色）；危险项红字；子菜单向右开；带当前值的父项把值写在右侧（13px 淡色）+ ›；单选项打 ✓；不可用项 40% 透明。行菜单默认向下、右对齐。

**3.7 多选**：Shift 点击选一段（可跨组），⌘ / Ctrl 点击单条切换；选中行用选中底；不出批量栏，行「···」菜单变成批量项（「置顶 N」「将 N 项…」）；Esc 清空。

**3.8 键盘**：侧栏是一组 roving 焦点（只有一个 tabIndex=0），↑↓ 移动、Home / End、Enter 打开；⌘1–9 跳转只在桌面窗口（浏览器里与切标签冲突），按住 ⌘ 时行尾数字提示替换装饰；菜单项单字母快捷键。

**3.9 标题栏**：高 32；会话标题是按钮（13/19、字重 500，「公司名 ›」同字号；点了就地改名），旁边「···」24（会话菜单）；右侧 26 的图标按钮：会话栏开关（`aria-pressed`）、文件等。
就地改名（2026-10-16 验收后用户批，Claude Code 实测）：输入框与标题同字号字重（电脑 13px / 500）、高一行（约 19）、透明底、无边框、圆角 3，聚焦只有 1.5px 蓝色描边、没有 6px 光晕；回车保存、Esc 放弃（输入法选字的回车不算）；文字与按钮里的标题对齐，不被 32 的标题栏裁掉。侧栏行的就地改名同一样式（用行字号，文字与行标题对齐）。32 的标题栏里的控件和侧栏搜索框，键盘焦点改用 1.5px 里描边（6px 光晕会被窗口顶边、栏边裁掉）。手机对话页没有标题，改名仍走胶囊菜单。

**3.10 对话区**：栏宽 768；正文 14/20（手机 16/24）；块之间只用上外边距：段落、列表、表格之间 0.75em（14px 时 10.5px），标题前 1.25em，第一块为 0；列表缩进 28 + 7；行内代码 0.9em、圆角 5；链接用链接色；用户气泡靠右、最宽约 580、底 叠色 5%、圆角 10、内边距 8/12、14/20；回复下的操作行（复制等，24 按钮 + 相对时间）悬停淡入，手机常显。
你发的消息里的附件（2026-10-16 验收后用户批，同 Claude）：气泡上方靠右，每个文件一张卡片（宽 120、缩略图区 128 高，整张约 2:3；圆角 10、1px 内环，同会话栏卡片）。图片显示缩略图（本页刚发的用本地预览，刷新后、别的设备上取服务端留存的那份）；PDF 与其他文件是文件图标 + 类型（没有在浏览器里画 PDF 首页的组件，不为它加依赖）。下面文件名一行（超长省略号）、类型说明：PDF 是「PDF · N 页」（页数由服务端按留存的那份读），其他是「XLSX · 12 KB」，读不出就只写类型。点卡片在右侧面板预览，与 CC 产出的文件同一个预览（PDF 也能看，修 S3）：服务端先取本站留存的那份（只认这个对话的、只读本地），没有再去引擎找可下载的结果（第 4 轮审查：缩略图、预览不再每张都先付引擎的列文件调用）；面板临时多列这一个附件，右上角「文件 N」仍只数结果。读屏名字「附件：名字 · 类型说明」跟页面语言。输入框里的附件小方块（移除、上传中、失败）照旧。

**3.11 工具步骤**：连续工具调用收成一行摘要：高 24、14px 淡色、圆角 6、内边距 2/4，文字如「已运行 2 个命令（1 个失败）」「已获取 6 个页面（6 个失败）, 已浏览 网页, 已运行 1 个命令, 已使用 1 个工具」，后面 12px 箭头。展开：摘要变次要色，下方卡片（圆角 10、1px 环），每步一行（内边距 6/8、行间 1px 线），只写一句说明；失败行尾红字「失败」；每步还能再展开看命令与输出（等宽）。
