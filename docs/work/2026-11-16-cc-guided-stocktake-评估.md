# 需求影响评估：CC 引导式 · 盘点（Cowork + ERP，P3 第 3 类）

> 总表 CW-D-ST、ERP-D-ST 两格（都不分账本）。基线：`pearnly/cc-guided-recon`（d88ac7a46，含引擎 N1–N10）。

## 0. 需求原文与理解

- 原话：用户 11-14「每个功能都要有引导式」；主会话 11-16「LINE / 网页已有成熟流程的格优先」，并认可 Cowork 与 ERP 的盘点一起做。
- 理解：CC 对话里点「盘点」，一张卡办四件事之一：新建盘点 / 记实盘数（连续录多行）/ 结束盘点 /（ERP）按结果生成调整单草稿。卡上选、卡上填，CC 不转述数量。
- 不在范围：盘点算法、快照、审阅令牌、调整单入账一律不动；删除盘点随「删除类」另做；拍照记数、扫码相机不在 CC（网页 / LINE 手机页已有）。

## 1. 现有同类与复用

- **Cowork 网页盘点页**（`stocktake/desk_api.py` 15 个接口）：新建（Excel，`upload.create`）、模板、按码 / 条码查（`api_stock_count_lookup`）、记一笔（`api_stock_count_add_entry`，同一物料累加）、重盘、审阅、结束（`api_stock_count_close`，带审阅令牌）、导出差异表；**LINE** 富菜单「盘点」用 LIFF 打开同一网页。
- **ERP 盘点页**（`inventory/count.py`）：新建（按仓快照，`create_count`）、按码查（`lookup_count`）、记一笔（`add_entry`）、审阅 / 结束（`review_count` / `close_count`）、生成调整单草稿（`adjustment_draft`）；**LINE** 富菜单第 3 格、手机盘点页（`inventory/line_mobile.py`，同一批接口）。
- CC 工具 `cowork_stocktake_*` / `erp_stocktake_*` 调的就是这两组；ERP「结束盘点」现有允许卡（用户 11-12：删除、结束类各一张卡）。
- 结论：**全部复用**。新建两个模块 `pearnly_cowork/assistant/guided/stocktake.py`、`pearnly_erp_portal/inventory/cc_guide_stocktake.py`（ERP 声明放产品域，照收款 `collection/cc_guide.py` 的做法；ERP 的架构登记允许 inventory 调 masters），只转调上面的函数。

## 2. Frappe 原生能力

- 不涉及 Desk；引导运行用已有表。

## 3. 按类通用

- 两个产品同一份题型：「做什么」一题 → 各自的后续步骤。连续录多行用引擎 N4（金额多选 + 搜索 + 允许 0）：一行 = 一件物料 + 实盘数，可一次录多行、可再开一张卡接着录。
- 「结束」要允许卡、「新建 / 记数」用普通确定：同一份声明里按「做什么」定确定的样子 → 引擎补一处：`consent` 可写成点路径（按这次的答案回 `allow` / `confirm`），本窗口在引擎分支上加（约定 N5 的延伸，登记进约定页）。

## 4. 上下游数据

- Cowork 盘点不写 Express（`stocktake/` 里没有推送）；ERP 结束只锁结果、不动库存，调整单只生成草稿，人在调整单页提交才入账（岳父 11-06 口径，不变）。
- 记数来源：ERP 记一笔带 `request_id`（`cc:<uuid>`，同 CC 工具）防重；Cowork 照 CC 工具。确定只办一次（引擎已保证双击不办两次）。
- 物料认不出、同码多件：选项本来就只列这份盘点里的物料（服务端搜索码 / 名称 / 条码），不会出现认不出的码；同码多件在选项里各列一行（带名称），由人点。

## 5. 隔离与权限

- 菜单：Cowork 有盘点功能的人（盘点页同一道 `stocktake` 权限）；ERP 有「盘点」功能的人（`count.write`，同 LINE 富菜单的判法）。
- Cowork 盘点不按公司隔开（用户 11-16）；ERP 按对话挂的那家公司（工具执行期间的当前公司 `masters.company.acting`，同 CC 工具），仓只列这家的。

## 6. 入口

- CC 对话：业务菜单「盘点」+ 说一句。网页盘点页、LINE 手机页不动。

## 7. 共用件与连带回归

- 新加两个模块、两产品 hooks `pearnly_guides` 各追加一项、术语表追加；引擎 `declaration.py` / `run.py` 的 consent 点路径一处（本窗口分支）。不改 `stocktake/*`、`inventory/count.py`。

## 8. 存储与成本

- 不新增存储、不调识别、不发 LINE、不新增固定月费。

## 9. 删除、作废、追溯

- 记错了：「记数」时勾「重盘」（同网页「重盘」：先作废这件物料已记的数）作为一题（做不做，不预选）；删除盘点随删除类另做。

## 10. 文案与官方 UI

- 新增词条（四语）：菜单「盘点」沿用两产品已有的「盘点」译文；「做什么」各项沿用盘点页按钮词（新建、结束盘点、按盘点结果调整物料）；步骤标题沿用盘点页列名（盘点、物料、实盘数、仓库、标题）。没有现成的才新增，不加说明文字。

## 11. 测试与验收

- 离线（照对账引导的替身写法）：做什么只列此刻能做的（没有进行中的盘点就不列记数 / 结束）；新建：Cowork 交 Excel、ERP 选仓；记数：选项只列这份盘点的物料、搜索、数量可为 0、一次多行、重盘；结束：允许卡、带审阅令牌、期间有人改了照页面口径拒；ERP 调整单草稿只在已结束的盘点上；确定只办一次；结果：新建回盘点号与跳过的行、记数回已盘几项 / 未盘几项、结束回差异表文件。
- 流程（接线后）：实验栈两产品各走一遍。

## 12. 要主会话定的点

| # | 问题 | 我的建议 | 不定的影响 |
| --- | --- | --- | --- |
| 1 | 「结束盘点」放进同一张「盘点」卡（按做什么切到允许卡），还是单列一个菜单项 | 同一张卡（菜单不挤；引擎补 consent 点路径） | 单列就是两份声明、两个菜单字 |
| 2 | Cowork 新建要不要在卡上给模板（结果卡给模板文件） | 要（做什么多一项「下载模板」，同盘点页的模板按钮） | 不给则用户要去网页拿模板 |

## 13. 工作量与排期

- Cowork 4–5 / 1.5、ERP 3–4 / 1（写码 / 机器 h），引擎 consent 点路径 0.5 / 0.5。服务端不等人。
