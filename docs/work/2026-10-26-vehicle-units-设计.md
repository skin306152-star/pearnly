按台盘点的界面草图（官方组件）、不接 Express 的完整流程。基线 main `d8d42e6f`，分支 `pearnly/vehicle-units`。

岳父答复（主会话 10-26 转）：只卖新车；车型 = 商品；车架号 / 发动机号 / 颜色代码每台一份；二维码 = 17 位车架号全号；
认不到二维码时用发动机号或车架号末 8 位；库位按通用做；不做金融、赠品、上牌。
第一个目标：**不接 Express 的公司**不靠 CC、不靠 Express 完整能用；Express 部分等服务器测试账套实录后再加。
基线要求：商品不开「按台管理」时，现有行为一点不变。

## 1. 按台记录的字段

新 DocType `ERP Serial No`（Frappe 原生，自有 App；站点不装 ERPNext，不能用它的 Serial No）。一台一条。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `product` | Link ERP Product，必填 | 车型（商品） |
| `company` | Link ERP Company，必填 | 进货时仓库所属的公司；读写按当前公司（`has_permission` + `permission_query_conditions`） |
| `serial_no` | Data 40，必填 | 主号：车 = 车架号（17 位全号）；其他商品 = S/N |
| `serial_key` | Data，唯一索引，只读 | `公司|主号`：同一家公司同一个主号只有一条（不跨公司校验，不泄露别家数据） |
| `secondary_no` | Data 40，加索引 | 副号：车 = 发动机号；其他商品 = 第二个号（如 IMEI 2），可空 |
| `serial_tail` | Data 8，加索引，只读 | 主号末 8 位（保存时算），认台的兜底 |
| `color` | Data 60 | 颜色代码，可空 |
| `status` | Select | `in_stock` 在库 / `sold` 已售 / `issued` 已出库 / `void` 作废 |
| `warehouse` / `location` | Link ERP Warehouse / Data 140 | 现在在哪个仓、哪个库位（在库时有值） |
| `in_doctype` / `in_doc` / `in_date` | Link DocType / Dynamic Link / Date | 哪张单进的（进货单 / 入库单） |
| `out_doctype` / `out_doc` / `out_date` | 同上 | 哪张单出的（销售单 / 收银小票 / 出库单），在库时空 |
| `note` | Small Text | 备注 |

商品加两格（ERP 自有字段，Express 不锁）：

- `track_serial` 勾选「按台管理」；开了以后数量必须是整数，进出都要登记台。已经有库存或单据的商品不能改开 / 改关（服务端拦），避免账上数量与台数对不上。
- `serial_kind` 选择：`vehicle` 车（主号 / 副号 / 颜色显示为 车架号 / 发动机号 / 颜色）、`device` 其他（显示为 S/N / 第二个号 / 颜色）。只决定显示的叫法，存的是同一套字段。

单据上登记的台：共用一个子表 DocType `ERP Line Serial`（istable：`line_no` 第几行、`product`、`serial` Link ERP Serial No、
`serial_no`、`secondary_no`、`color`），挂到四种单：`Purchase Document`、`ERP Sales Document`、`ERP Sale`（收银）、`ERP Stock Entry`，
字段名都叫 `serials`。Frappe 子表不能再套子表，所以台挂在单据上、用行号对回明细行；不改现有明细行和 `ERP Stock Movement` 结构。

## 2. 选台流程

库存流水照旧按商品走数量，台只跟着单据改状态。全部在服务端过账那一步做，与流水同一个事务。

| 单据 | 页面上 | 过账时（服务端） | 作废时 |
| --- | --- | --- | --- |
| 进货单（带入库）、入库单「其他」 | 按台商品的行多一个「登记车辆」按钮 → 原生 Dialog + 可编辑 Grid（车架号 / 发动机号 / 颜色），扫码图标扫二维码填车架号；行数量 = 登记的台数 | 台数 = 数量，主号本公司没有在库 / 已售的同号；新建台，状态在库，记进的单与仓 / 库位 | 这张单进的台都还在库 → 改作废；有一台已经卖出 / 出库 → 不让作废（报「已售出的车辆不能随单作废」），先作废卖出的单 |
| 入库单「退货」 | 从本公司「已售」的台里选（Link 搜索） | 台改回在库，仓 / 库位按这张单 | 退回已售 |
| 销售单（带出库）、收银、出库单 | 按台商品的行「选择车辆」→ Dialog 里一个 Link（`get_query` 走服务端分页搜索：只出这个仓在库的、这个车型的；搜主号 / 副号 / 末 8 位）+ 扫码图标；选几台数量就是几 | 台必须在库、在这个仓、是这个车型；改已售（收银、销售单）或已出库（出库单），记出的单 | 台退回在库、原仓原库位 |
| 收银退货（`return_against`） | 只能选原小票卖出的那几台 | 台改回在库 | 退回已售 |

- 认台（扫码 / 手输）：主号全等 → 副号全等 → 末 8 位全等，只认本公司的、唯一的那一台；认出几台不自动选，列出来让人点。
  这一套也接进 `product_of_code`：扫到车架号能直接认到车型（商品页、收银台、盘点、单据行扫码共用入口，按共用件逐入口回归）。
- 数量与台数不符、同号重复、台不在这个仓：服务端拒，过账不成，页面原生 msgprint 报。
- 不开按台的商品：没有这两个按钮，过账不碰 `serials`，行为不变。

## 3. 按台盘点界面草图（官方组件）

盘点行仍是 商品 × 仓库 × 库位，按台商品的「账面数量」= 这个仓位在库的台数。

```
盘点录入（frappe.ui.Dialog，现有的那个）
┌──────────────────────────────────────────────┐
│ 码  [ MP1TFR86JRT000123        ] [扫码图标]   │  ← 现有 Data + 扫码图标，扫车架号二维码
│ 车型  ISUZU D-MAX 1.9 Spark（P-000031）       │
│ 仓库 / 库位  主仓 / A-01                      │
│ ── 这个仓位的车辆（原生 DataTable，只读） ── │
│ 车架号              发动机号     颜色  状态   │
│ MP1TFR86JRT000123   4JK1-55120  W01   已盘 ✓ │
│ MP1TFR86JRT000456   4JK1-55377  B02   未盘   │
│ 数量  2 台中已盘 1 台                         │  ← 数量不手输，按扫到的台算
│                               [ 记一台 ]      │
└──────────────────────────────────────────────┘
```

- 扫一台记一条盘点记录：`ERP Stock Count Entry` 加 `serial`（Link），数量固定 1；同一份盘点里同一台再扫，提示「该车辆已盘」不重复记。
- 扫到的台在别的仓位：照现有「这件货的账在别处」逻辑摆出来，记在实际位置（台的仓 / 库位在过账时跟着改）。
- 扫到系统里没有的车架号：不建台，报「找不到这辆车」（盘点不进新车，新车要走入库）。
- 盘点工作台、差异报表：按台商品多一列「未盘到的车辆」（主号列表）；Excel 导出多一列车架号。盘点 Excel **导入**对按台商品只认逐台一行（填车架号），按数量导入的行拒收。
- 过账：数量差异照现有逻辑出入库流水；扫到的台更新仓 / 库位；没盘到的台**不自动改状态**（要不要标「盘亏」等主会话定，见第 6 节）。
- LINE 手机盘点页同一套（扫码 → 记一台）。

## 4. 不接 Express 的完整流程

公司没接 Express 时，下面整条在 ERP 里走通，不依赖 CC、不依赖 Express：

1. 商品：建车型，勾「按台管理」、种类选「车」，内部编码照常可填。
2. 进货：采购单 / 进货单录车型、数量 3 → 「登记车辆」录 3 台（扫二维码或手输）→ 入库过账：3 台在库，账上数量 +3。
3. 看库存：库存一览照旧按车型显示数量；按台记录列表（原生 List，按当前公司）看每台在哪、什么状态，能按主号 / 副号 / 颜色 / 状态筛。
4. 卖：销售单或收银选车型 →「选择车辆」扫码选台 → 过账：台改已售，账上 −1。
5. 打印：销售 / 进货 / 出入库单据在按台商品行下印 车架号 / 发动机号 / 颜色（打印第二批的单据模板按此留位置；第一批的领料单、收货单同样在行下印）。
6. 盘点：按第 3 节。
7. 作废 / 退货：按第 2 节表格。
8. 库位：台记仓 + 库位；库位清单做完第 5 项后从清单选。

接了 Express 的公司：这次同样能开按台、能用上面整条，只是车号只在 ERP 里——写进 Express 的单据照现在的写法，不带车号。
Express 那边写附加说明（`ARTRNRM`，行号对应与打印位置）等服务器测试账套实录后再加，届时升载荷版本、CC 回归。

## 5. 改动面、共用件与成本

- 新 DocType 2 个（`ERP Serial No`、`ERP Line Serial`），商品 2 格，四种单据各加 `serials` 子表，盘点记录加 `serial`；都走原生迁移。
- 共用件：`product_of_code`（扫码共用入口）、各单据过账 / 作废路径；按 `scripts/impact/shared-parts.toml` 登记新入口（进货登记、销售 / 收银 / 出库选台、盘点扫台），逐入口实测。
- 不加外部调用、不加月费；数据量每台一行。
- 估时（机器耗时）：写代码约 6 小时；离线回归 + 实验栈逐入口约 3 小时。
