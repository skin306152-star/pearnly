# ADR-007 原生 Desk 视觉与 Pearnly 品牌色

状态：2026-09-20 按用户明确要求修订，配合 ADR-005。

产品 Web 复用管理后台同一套原生 Frappe Desk 布局、控件、提示和弹窗。浅色模式保持官方白色表面、深色正文、灰色边框及原生尺寸/留白。保留原生主题偏好；不再把所有页面刷成浅紫背景、紫色正文。

品牌紫 `#7c4dff` 及悬停 `#6b3ff2` 只用于主要操作和选中强调。状态色沿用官方语义：成功绿色、错误红色、警告橙色。不得把成功排队提示标成错误。样式作用域只覆盖产品 Site 的 `.pearnly-product-desk`，不能影响本地控制面。

默认用 Page 工具栏、Workspace Sidebar、FieldGroup、Dialog、Grid/DataTable。业务需要的内容与动作允许组合，但不复制通用弹窗、表单或提示组件，不用原生浏览器 alert/confirm 代替 Desk。

语言和账户偏好复用左下角原生 User 设置，不在页面顶部重复添加。仅显示当前产品已实现且有权限的业务入口；原生框架自带但未承接的管理、网站、帮助等入口不直接暴露。登录账户由 Keycloak 管理时，个人页改密使用官方 AIA 校验当前密码后设置新密码，不修改另一套 Frappe 本地密码。

提示音调用官方 play_sound，遵守 mute_sounds 和浏览器自动播放限制。不能保证未发生用户交互时浏览器必定发声，也不覆盖用户静音选择。

LINE 票据编辑器保留官方 Frappe UI 控件；Keycloak 保留原生认证主题。邮件是独立的兼容邮件客户端 HTML 卡片，不加载 Desk 或 Vue。

验收既看实际组件来源，也看成功、错误、取消、重复提交、权限、窄屏、语言和真实运行状态。只换配色或标签不算框架对齐。


2026-09-20 产品入口收口：官方组件的复用不授权开放其附带产品能力。入口需有实现、购买功能、用户权限、正确去向与场景证据；具体核对表放在当前工作记录。产品端关闭尚未承接的全局搜索/站内通知，根桌面返回业务首页；保留本机控制面的原生功能。个人设置不展示框架文档协作和独立于统一身份的会话管理。未实现的推送记录、投递链和其他业务页单独登记为缺口，不因隐藏而算完成。
