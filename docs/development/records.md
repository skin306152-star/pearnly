# 开发记录规范

目的：让下一个开发者或 Agent 能判断做了什么、依据什么、验证到哪、接下来做什么。记录跟随代码，不把聊天全文复制到仓库，也不在产品数据库中建立开发台账。

## 只保留各自负责的一份正本

| 内容 | 正本位置 | 何时更新 |
| --- | --- | --- |
| 常驻 Agent 约束 | 根 `AGENTS.md` | 工作方式或边界改变 |
| 开发方法、检查选择 | `CONTRIBUTING.md`、`docs/development/` | 命令、流程或要求改变 |
| 版本和兼容性 | `docs/p1/01-version-matrix.md` + 构建定义/锁文件 | 实际选定版本或兼容性改变；相互核对 |
| 架构决定 | `docs/adr/` | 底座、边界或长期契约改变 |
| 一个工作包的范围、证据和交接 | `docs/work/YYYY-MM-DD-topic.md` | 多步骤任务开工、重要转折、交付/中断 |
| 简单小修 | 提交或 PR | 说明行为与必要检查即可 |
| 发布/回退回执 | `docs/releases/YYYY-MM-DD-topic.md` | 任务实际进入发布时；不为未发布版本造回执 |
| 产品技术说明 | 对应模块文档 | 行为、接口或配置发生变化 |

`docs/p0` 到 `docs/p4` 保留为历史阶段证据，不重编号、不把所有旧状态句改成现在。当前工作需要引用旧结论时，在新记录中说明哪条被后续结果取代；可在旧入口加简短后继链接。

## 工作包的最小内容

从 [模板](templates/work-package.md) 建立，字段按任务缩减：

- 目标与完成条件；本次明确不做什么。
- 当前范围状态：进行中、阻塞、待审查或本次范围完成。它不等同于部署和用户验收状态。
- 仓库、分支、基线 SHA、工作树、集成目标、实际合并与远端同步状态；迁移来源的首次/最后线上核验时间、revision、digest、源码 SHA、配置范围和路径。
- 文件/资源归属、依赖任务、必要授权及未授权操作。
- 最终变更与重要决定；不要保留所有失败尝试的流水账。
- 验证表：代码版本、环境、场景/命令、预期/实际、结果和证据位置。
- 未覆盖项、阻塞点、下一步，及本任务资源的保留/清理结果。

迁移记录还必须满足 [线上基准规范](migration-baseline.md)：首尾版本有变化时登记增量影响和补迁结果。分支已 push、代码已合并、服务器已运行分别记录，不以“已同步”一词混用。

未提交时，记录基线和明确的差异范围；交付后以包含记录的提交/PR 识别最终版本，不在同一提交里填一个无法自指的 SHA。长期任务可补独立的验证提交或发布记录来固定精确候选。

结论发生变化时写“原判断 → 新证据 → 当前结论”。不可直接擦掉失败记录，把尚未重跑的检查改成通过。多人同时开发只改各自工作包，不争用全仓唯一的 `STATE.md`。

## ADR：只记值得长期保留的选择

沿用现有编号和 [ADR 索引](../adr/README.md)，新建前查占用；现有 `0003`、`0004` 已预留，不能拿来登记本次流程。
用 [ADR 模板](templates/adr.md) 写问题、约束、选项、决定、代价和验证/迁移影响。状态为提议、已采纳、废止或被替代，并链接后继。

已有用户决定不因 ADR 尚未成文而反复要求确认；记录依据和仍缺的细节即可。开发 Agent 不能把自身建议直接记为用户已决定。普通函数拆分和小修无需 ADR。

## 证据和敏感信息

- 截图与小型脱敏证据可放工作包同名子目录；大日志、备份、原始身份证/单据留在受控存储，只记录可定位的引用和必要摘要。
- 不提交密码、token、会话票据、服务账号 JSON、未脱敏客户资料；不把完整 `docker inspect` 环境输出当证据。
- 证据文件名应关联工作包和场景，避免其他任务覆盖同名截图。使用仓库相对链接，便于换机与审查。
- 临时绝对路径可作为本机环境描述，但不能成为唯一交接依据。无法访问的外置计划包须明确，不假装新同事已经能读到。

## 维护与例外

改接口同步接口说明；改脚本同步用途、副作用和调用方式；改版本同步兼容矩阵；改架构同步 ADR；交付只更新本次工作包和必要入口。不要求每次修复手动刷新全部文档。

无法完成某检查时记录原因、影响、负责人/后续工作和恢复条件。确需临时偏离工程要求时记录适用范围与失效条件，并区分尚未满足的授权；“有例外记录”本身不允许关闭权限、破坏数据或绕过既有强制闸门。

合并和发布分别留真实结果。没有远端 CI、分支保护、自动化结果就写未接入/未核实；不能把规范文本、PR 模板或本地 hook 当成已经强制执行的证明。
